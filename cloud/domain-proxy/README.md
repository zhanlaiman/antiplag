# Бесплатный домен Истока

Этот Worker передаёт HTTPS-запросы с `istoktext.online` и `www.istoktext.online`
только на опубликованный CPU-сервис Modal. Платный custom domain Modal не нужен.
База и обработка остаются в Modal. Worker не хранит тексты, ключи, журналы запросов
или резервные копии; ответы не кэшируются. Авторизация, квота и очередь проверяются
прежним сервером. Cookie и Origin передаются с проверкой исходного домена.

## Подключение

1. В аккаунте владельца Cloudflare добавить `istoktext.online`, выбрать **Free**.
   Проверить импортированные записи, сохранить нужные MX/TXT, если они есть.
2. Скопировать две выданные Cloudflare NS. В Namecheap → Domain → Nameservers
   выбрать Custom DNS и записать именно эту пару. Это делегирование DNS Cloudflare;
   регистрация и продление остаются у Namecheap. Откат — прежний Namecheap BasicDNS.
3. Дождаться статуса Active. В Workers & Pages создать Worker `istok-domain`
   с содержимым `worker.mjs`. Платный Workers plan, хранилища и аналитика не нужны.
4. Добавить custom domains `istoktext.online` и `www.istoktext.online`.
   Сначала удалить конфликтующие парковочные A/CNAME/URL redirect для этих двух
   имён. Не удалять MX/TXT и чужие поддомены. Cloudflare создаёт DNS и TLS.
   Либо после входа владельца выполнить `npx wrangler deploy` из этого каталога.
5. Проверить HTTPS, отсутствие кэширования `/api/session`, гостевую изоляцию,
   вход владельца, создание библиотечного отчёта, reload и экспорт. Живой поиск
   не нужен, если эти изменения не затрагивают поисковый движок.

Гостевая cookie старого адреса Modal не переносится на новый домен. Старый адрес
и отчёты остаются доступны в прежнем браузере. Владелец может войти на новом домене
в своё постоянное пространство; нельзя автоматически привязывать нового гостя.

## Ограничения и откат

Free Workers: 100000 запросов в сутки и 10 ms CPU на запрос по документации,
проверенной 13 ноября 2026. Исчерпание бесплатного лимита означает недоступность
домена до восстановления квоты; платный fallback не настроен. Старый адрес Modal
остаётся независимым. Worker не является способом увеличить поисковую квоту.

Откат Worker — предыдущая версия через Deployments. Для полного удаления шлюза
удалить два custom domains и вернуть прежние NS/записи, если нужно. Данные Modal
и квотный журнал при этом не откатывать. При сбое запроса не повторять POST
проверки с новым ID: восстановить прежнее задание по существующему ID.

Проверка перед публикацией: `node --test tests/domain-proxy.test.mjs` из корня.
Вход в аккаунт, согласие с условиями и смена NS выполняются владельцем либо
после его явного поручения. Файлы готовы к публикации; наличие файлов не означает,
что зона или Worker уже опубликованы.
