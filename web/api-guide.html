API бесплатной беты

Войдите как владелец и откройте «Мои данные → Доступ через API». Создайте ключ с нужными разрешениями. Он показывается один раз, действует до 90 дней и отзывается в этой же панели. До трёх активных ключей. Полный ключ храните в секрете; сервер хранит только его хеш.

Базовый адрес — текущий адрес сайта. Все запросы требуют заголовок Authorization: Bearer ВАШ_КЛЮЧ. Cookie не нужна. Ключ нельзя передавать в URL или включать в публичный клиентский JavaScript. Запросы из чужого браузерного Origin запрещены; API предназначен для серверных интеграций.

Укажите честный User-Agent с названием вашей интеграции, например User-Agent: MyIstokClient/1.0. Cloudflare может отклонить стандартный User-Agent библиотеки Python urllib с кодом1010 ещё до обращения к API. Имитировать браузер не нужно; инструкция Cloudflare.

POST передаётся как JSON с Content-Type: application/json. Источник: {"title":"Название","url":"https://example.org/article","text":"Текст источника"}. DELETE переносит источник в корзину; восстановление доступно в панели владельца. Служебные API управления моделью и ключами через Bearer закрыты.

Для интернет-проверки заранее создайте и сохраните случайный request_id: 32 строчные шестнадцатеричные цифры. Отправьте:

POST /api/v1/checks
{"request_id":"СОХРАНЁННЫЕ_32_HEX","text":"Ваш текст","internet_consent":true}

Этот прежний формат передаёт поисковые фразы Tavily и, при дополнительном поиске, Википедии. Для Google через SerpApi добавьте оба поля "search_provider":"serpapi","provider_consent":"serpapi"; одного согласия на Tavily недостаточно. Сервер читает найденные сайты. Не передавайте секретные тексты. Гостю — до 10000 знаков; у владельца нет лимита знаков целевого текста, один JSON-запрос — до 2 МБ. Источник — до 10000 знаков в бете. Исходный файл через этот API не импортируется.

Ответ содержит job. Читайте GET /api/v1/jobs/{request_id} до complete или failed; рекомендуется пауза 3–5 секунд. При complete результат доступен в job.result.report и через GET отчёта по его ID. Отсутствие совпадений не доказывает уникальность; проверяйте статус охвата и прочитанные страницы.

При потере ответа сначала запросите прежнее задание по ID. Повтор POST с тем же ID и тем же текстом возвращает прежний результат без нового поиска. Тот же ID с другим текстом отклоняется. При failed не создавайте новый ID автоматически: неизвестный исход сохраняется как израсходованный, повтор может потратить новую квоту.

До 120 API-запросов в минуту на ключ и до 40 изменяющих действий в сутки на пространство. Поиск расходует ту же общую месячную квоту сайта — до 180 основных запросов, а не 180 документов. Ключ не создаёт новую квоту. Владелец сохраняет свой существующий режим дневного ограничения. Источники — до пяти собственных сверх подборок; корзина лимит не освобождает.

Ошибки: 400 — неверные данные/согласие, 401 — нет ключа, он истёк или отозван, 403 — Origin/разрешение, 404 — нет доступной записи, 409 — конфликт задания, 429 — квота или частота. JSON содержит error и при наличии code. Для частоты API возвращается Retry-After; его нужно соблюдать. Автоматического платного fallback нет.
