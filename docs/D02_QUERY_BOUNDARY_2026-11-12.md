# D02: свежая проверка границы поисковой фразы

[Исходная фраза с посторонним словом](http://127.0.0.1:8766/#check/9f4f2db3d4e86be0812081502c6843b3) · [Чистая девятисловная фраза](http://127.0.0.1:8766/#check/d62e437a65164b094802d16e0db7f292)

Удаление начального слова «особенность» не восстановило источник в этой паре свежих проверок. В обоих случаях Tavily не вернул ожидаемую статью «Почтовая марка», и девять слов вставки остались без подсветки. Для чистой фразы подтверждён пропуск на этапе получения ссылки. Одного постороннего начального слова недостаточно, чтобы объяснить весь пропуск D02.

| Результат | Исходная фраза → чистая фраза | Объём проверки |
| --- | --- | --- |
| Слов в отправленной фразе | 10 → 9 | Один запрос каждого вида, один документ |
| Нужный URL в выдаче | 0/1 → 0/1 | Один ожидаемый источник каждого вида |
| Нужный источник прочитан | 0/1 → 0/1 | Один ожидаемый источник каждого вида |
| Нужный фрагмент подсвечен | 0/1 → 0/1 | Один девятисловный фрагмент каждого вида |
| Слов вставки подсвечено | 0/9 → 0/9 | Один документ каждого вида |
| Подтверждённых ложных подсветок | 0 → 0 | Подсветок вообще нет в обоих отчётах |
| Всего страниц прочитано | 5 → 7 | Один документ каждого вида |
| Документов без прочитанных страниц | 0/1 → 0/1 | Один документ каждого вида |
| Фактических поисковых запросов | 1 → 1 | Два Tavily Basic запроса суммарно |

Исходный запрос занимает позиции `[248, 340)` в неизменённом D02, чистый — `[262, 340)`. Обе фразы получены планировщиками только из проверяемого текста: исходный `hybrid-citation-v2` с лимитом один и тот же планировщик с единственным изменением границы предложения — пробельное длинное тире завершает часть предложения. Правильный URL и разметка планировщикам не передавались. Полный текст D02 отправлялся в обычную HTTP-очередь с согласием на интернет-проверку; поисковый API получил только соответствующую фразу.

Проверки выполнены последовательно 11 ноября около 23:53 по Алматы. В обоих вариантах сохранено обычное чтение страниц и переходов по содержательным ссылкам, явно закреплён одинаковый порядок доменов. Экспериментальные идентификаторы стратегии и фактические границы фраз записаны в отчётах. Сравнение использует одну свежую выдачу каждого вида, поэтому не измеряет устойчивость поискового сервиса.

В исходной проверке один большой PDF не прочитан, отчёт частичный. В чистой проверке все запланированные страницы прочитаны, ошибок загрузки нет. Её `complete` относится к выполненному плану, а 100% несовпавших слов — к семи прочитанным страницам. Известная вставка при этом пропущена. Такой процент не подтверждает отсутствие заимствований во всём интернете.

Глобальное правило разделения по тире не включено: отдельный локальный эксперимент уже обнаружил 22 потерянные вставки на длинных искусственных примерах. Этот парный опыт также не дал выигрыша, который оправдывал бы его включение. Возможная следующая гипотеза — добавить предметный контекст к неоднозначной фразе про «гашение»; свежая выдача для такой гипотезы не проверялась, дополнительных запросов здесь не было.

Перед отправкой `quota(2)` подтвердил Researcher, 39/1000 использованных запросов по счётчику провайдера, 151 попытку в локальном журнале и нулевой платный перерасход. Две отдельные записи API подтвердили по одному кредиту Basic. После пары в локальном журнале 153 попытки, платный перерасход остаётся нулевым. Счётчик использования плана провайдера ещё показывал 39: стоимость этой пары подтверждается её двумя записями `usage.credits=1`, а не разницей запаздывающего общего счётчика. Расход: **два бесплатных запроса, 0 ₸**.

Оба отчёта сохранены в основной базе сайта; `GET /api/reports/<id>` вернул HTTP 200 для каждого. Повторное выполнение скрипта восстановило оба завершённых задания через GET по сохранённым идентификаторам, без нового POST и без поиска. Для каждого поискового идентификатора в журнале ровно одна запись. Код основного сайта не менялся; версия основного кода при запуске — `20ada1e`.

Приватные материалы находятся в `data/private/web-evaluation/dev-d02-clause-pair-live-v1`: `run.json`, два файла `*-request.json`, два ответа `*-search.json`, `original.json`, `clause.json`, `comparison.json`, снимки квоты и `get-recovery-check.json`. Права файлов — 0600, в Git они не попадают. Финальные 70 не открывались. Скрипт — `scripts/run_d02_clause_pair.py`; два теста планирования на авторском тексте прошли. Недельный лимит Codex и бесплатный сброс во время этого опыта не читались и не вызывались.
