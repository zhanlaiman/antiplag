# Проверка производственного пути PDF

Проверен полный локальный путь: существующий PDF worker → настоящий транспорт `Fetcher` с замкнутой сетевой границей → нормализация → дополнительное представление → `analyze_with_supplements` → повторная проверка доказательств оценщиком. Использованы сохранённые PDF-байты; новых загрузок, поисков и модельных вызовов нет. Флаг PDFium включался только внутри процесса проверки. Установка пакетов и изменение конфигурации запуска не выполнялись.

Основной парсер — pypdf 7.0.1, дополнительный — pypdfium2 5.14.0, native PDFium 156.0.8076.0. Дополнительная exact-выдержка проходит только при допустимом Unicode и наличии тех же непробельных символов в том же порядке в основном тексте. Обе строки и координаты сохранены независимо; счётчики считают один физический источник.

| Сохранённая проверка | Результат |
| --- | --- |
| D06, нужная выдержка | 7 → 8/8 слов |
| D20, сам настроечный текст против этого PDF | 0 → 0; улучшения здесь нет |
| D16, сам настроечный текст против этого PDF | 0 → 0 |
| Девять дословных контролей трёх PDF | 9/9 сохранены |
| D16, восемь слов, сверенных с изображением страницы | 8 → 8/8 |
| Один авторский независимый текст против трёх PDF | 0 подсветок в 3 парах |
| Три примера ошибочного соединения слов/колонок и два математических примера | Новых необоснованных частей не появилось; результаты совпали с выбранным сохранённым фильтром |

В последних пяти примерах часть слов действительно присутствует в источнике и остаётся подсвеченной. Например, в некоторых контролях сохраняются шесть корректных слов; это не объявляется отсутствием всех подсветок. Ошибочно слитые слова и неподтверждённая последовательность не получили новой подсветки. Извлечение трёх PDF заняло 0,704 / 0,536 / 0,366 с в одном локальном прогоне.

## Первая проверка ранее закрытого PDF

Политика и хэши пяти производственных файлов зафиксированы в [night-pdf-choice-2026-11-12.json](baselines/night-pdf-choice-2026-11-12.json) до чтения RFC8259. Проверка началась только после успешного повтора трёх известных PDF. Фактические хэши кода совпали с зафиксированными. После раскрытия политика и выбор выдержек не менялись.

По замороженному правилу взяты девять искусственных дословных выдержек по 10/20/40 слов с позиций 25/50/75% основного текста. Начало — `min(floor(N × доля), N − длина)`, затем используются исходные координаты токенов. Два независимых контрольных текста также зафиксированы заранее.

- Один PDF, девять зависимых выдержек: 210 → 210 из 210 слов; все девять сохранены.
- Два фиксированных независимых контроля: 0 → 0 подсветок.
- Недостоверных выдержек: 0. Время извлечения — 0,337 с.

Это проверка сохранности основного результата и двух отрицательных пар. Выдержки взяты из основного извлечения, поэтому полный исходный результат задан построением. Она не измеряет независимый прирост полноты PDFium или общую точность на публикациях. Фактически доступен один новый PDF; отказы двух других URL сохранены отдельно и не включены как успешное извлечение.

Полные частные результаты находятся в `data/private/web-evaluation/pdf-production-validation-v1`: `known-integration.json`, `RFC8259-first-use.json`, сохранённые представления и маркер первой попытки. Там есть пары текстов, координаты, SHA байтов/строк, версии парсеров и доказательства. Маркер предотвращает неявный повтор первой проверки. Финальные 70 не открывались.

## Восстановление сохранённых представлений

В `load_source_pool` исправлено объединение двух строк одного URL. Теперь основной текст остаётся основным, PDFium восстанавливается как `supplemental_texts` с его SHA и числом страниц. Более новый снимок только с основным текстом не наследует дополнительный вариант из старого PDF. Сиротское представление не становится отдельной прочитанной страницей. Три новых проверки довели набор тестов повторов до десяти; все прошли.

При целевом прогоне также прошли 17 PDF-тестов и 24 теста загрузчика, включая реальные проверки уже установленного PDFium. Полный серверный и интерфейсный прогон выполняется отдельно для итогового снимка кода.

## Повтор всех 30 исходных отчётов

Дополнительные представления трёх PDF добавлены к исходным сохранённым источникам только при точном совпадении SHA основного текста. Все основные и остальные источники оставлены без изменений. Сравниваются два запуска одного производственного matcher: только основные тексты и те же тексты с тремя PDF-представлениями. Сети, повторного извлечения PDF и новых поисков нет.

На 30 документах представления применимы к трём. Единственное изменение — D06: 7 → 8 слов. Потерь слов и изменений контрольных документов нет; число физических прочитанных источников сохранено во всех 30 случаях. Недостоверных выдержек не обнаружено.

В 18 размеченных дословных фрагментах имеется 283 скопированных слова. Подсветка по любому подтверждённому источнику выросла 211 → 212 / 283; строго по ожидаемым URL осталась 98 → 98 / 283. Новое слово подтверждено другим PDF-источником, отсутствующим среди ожидаемых URL этого фрагмента. Это восстановление дословного совпадения; прибавки к строгому показателю ожидаемых источников нет.

Артефакт: `data/private/web-evaluation/pdf-production-validation-v1/cohort-30-same-primary.json`, с хэшами неизменённых снимков, сравнениями обоих запусков и отдельным подсчётом ожидаемых URL.
