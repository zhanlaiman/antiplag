# Повтор сохранённой выдачи: 12 ноября 2026

`scripts/replay_saved_dev_search.py` повторяет обычный `web_search.run` с сохранёнными ответами на конкретные поисковые фразы и сохранёнными текстами страниц. По умолчанию сеть выключена. Правильные URL из разметки не передаются поиску, очереди или загрузчику. Финальные 70 случаев не открываются. Отчёты имеют новые ID и сохраняются только в частные файлы, без записи в основную базу сайта.

Исходный прогон `dev-live-30-v1` не сохранил раздельную выдачу каждого запроса. Его плоский `discovered_urls` не превращается в выдуманные группы. Поэтому сравнение ниже использует раздельные ответы свежего прогона `dev-dense-six-live-v1`. При повторе старой стратегии по совпадающим фразам происхождение выдачи также остаётся этим свежим прогоном. Кэш текстов включает все 30 исходных DEV-отчётов и шесть отчётов свежего прогона.

## Одинаковая выдача и одинаковый кэш страниц

Оба порядка используют текущий механизм приоритетного перехода по связанной странице. Меняется только отбор поисковых URL: `domain-round-robin-v1` → `hybrid-domain-query-v2`. Новых поисков и загрузок страниц в этих сравнениях **0**.

| Случай | Дословно подсвечено слов: до → после | Прочитано сохранённых страниц: до → после |
| --- | ---: | ---: |
| D05 | 12 → 12 | 3 → 2 |
| D08 | 11 → 11 | 6 → 5 |
| D20 | 11 → 25 | 5 → 7 |
| D04 | 7 → 7 | 6 → 8 |
| D03 | 20 → 20 | 6 → 5 |
| D16, независимый контроль | 0 → 0 | 4 → 3 |

На шести случаях потерь подсвеченных слов нет. Выигрыш D20 — 14 слов второй вставки. Число прочитанных страниц само по себе не означает улучшение: в четырёх случаях новый порядок читает меньше сохранённых текстов при той же подсветке. Это повтор известных примеров, а не независимая оценка точности.

Часть выбранных URL не сохранена, а старые текстовые снимки не содержат ссылок и их подписей. Все такие ограничения перечислены в `offline_replay`, результат остаётся частичным, окончательная уникальность — `null`. Если страница уже недоступна в сохранённом исходе, инструмент не повторяет её загрузку автоматически.

## D04: настоящая ссылка со страницы

При исходном повторе только текстовых кэшей D04 давал ноль слов: текста родительской страницы было достаточно для сравнения, но не было настоящих ссылок, необходимых для перехода. Инструмент не подставлял ссылку или подпись из разметки.

После отдельного разрешения выполнены 10 прямых попыток чтения сайтов поверх прежних шести сохранённых поисковых ответов: шесть успешны, четыре завершились установленным отказом. Поисковых API-вызовов **0**. Нормальный загрузчик соблюдал robots.txt. Затем полностью локальный повтор сохранил все семь контрольных слов D04.

| Прямая попытка | Результат |
| --- | --- |
| [Иванов Павел](https://ru.wikipedia.org/wiki/Иванов_Павел_(опера)) | Обновлён известный родитель; сохранены реальные подписи ссылок |
| [Спектакль в музее Рерихов](https://spbvedomosti.ru/news/culture/v-muzee-institute-semi-rerikhov-sostoyalas-premera-spektaklya-ivanov-pavel/) | Новый выбранный URL прочитан |

| `files.znu.edu.ua/files/Bibliobooks/Inshi55/0040898.pdf` | `response_too_large` |

Ещё две страницы прочитаны из исторического кэша: [Пифагоровы штаны](https://ru.wikipedia.org/wiki/Пифагоровы_штаны) и [петербургский спектакль](https://spbvedomosti.ru/news/culture/vybiraem-po-sebe-v-peterburge-proshla-premera-spektaklya-krasnyy-fonar/). Они не объявляются заново загруженными. Нужный URL «Пифагоровых штанов» был выбран алгоритмом по реальной ссылке с обновлённого родителя, затем сверка использовала сохранённый текст этой страницы. Всего в отчёте D04 восемь прочитанных страниц, 12 попыток, семь найденных слов. Исторические тексты двух страниц всё ещё не содержат собственной полной метаинформации о ссылках, поэтому ограничение явно остаётся.

Полные ответы загрузчика, включая подписи ссылок, хранятся в `data/private/web-evaluation/dev-replay-page-cache-v1`. Перед сетевой попыткой сохраняется намерение `submitted`; ошибочный или неопределённый исход не повторяется автоматически. Семь локальных тестов проверяют отсутствие неявной сети, сохранение неопределённого исхода, запрет выдуманных подписей и невозможность загрузить URL вне настоящей выдачи или настоящих ссылок страницы.

Артефакты:

- `dev-saved-replay-domain-cached-links`: старый порядок, текущий механизм перехода, сеть выключена.
- `dev-saved-replay-balanced-cached-links`: новый порядок, тот же кэш, сеть выключена.
- `dev-saved-replay-d04-refresh-and-fill`: единственная отдельная прямая проверка страниц D04, поиск сохранённый.
- `dev-saved-replay-comparison.json`: сравнение и перечень реально загружавшихся URL.

Все пути выше находятся в `data/private/web-evaluation/` и исключены из Git. Воспроизведение без сети:

```sh
python3 scripts/replay_saved_dev_search.py --ids D05 D08 D20 D04 D03 D16 --url-strategy hybrid-domain-query-v2
python3 -m unittest discover -s tests -p test_saved_dev_replay.py -v
```

Флаги `--fill-missing-pages` и `--refresh-missing-links` отдельно включают прямое чтение выбранных страниц. Они никогда не включают поисковый API. Эти смешанные повторы следует отделять от полностью локальных результатов и от свежего интернет-поиска.
