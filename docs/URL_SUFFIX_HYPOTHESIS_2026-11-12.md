# Проверка русских окончаний в порядке URL

Вариант отклонён для включения по умолчанию. Он не восстановил пропуски D08/D10, а на свежей сохранённой выдаче D06 вытеснил уже полезный PDF за предел двенадцати загрузок.

До подсчёта побед и потерь записаны неизменные правило и список обычных окончаний: `docs/baselines/url-suffix-tiebreak-2026-11-12.json`, SHA `b8aa0f08cad11c80c2bd98248e00ec92c98b7154229be1205d88e4e08f06ef65`. Только русские слова, снятие одного самого длинного окончания, остаток не короче четырёх букв. Сходство после снятия окончания служит вторым ключом; прежний приоритет точных слов всегда первый. Селектор получает только целевой текст и декодированный путь URL, без эталонов и текста страниц. После результатов правило не менялось.

| --- | ---: | ---: | ---: |
| Предыдущие 30 DEV, выбранный полный вариант | 16/18 → 16/18 | 264/283 → 264/283 | 139/283 → 139/283 |
| Свежие D01–D12, тот же ответ поиска для обоих порядков | 9/13 → 8/13 | 111/152 → 103/152 | 72/152 → 72/152 |

Это **локальный условный повтор**, а не новый интернет-поиск. Исходный контроль воспроизвёл 30/30 ранее сохранённых отчётов выбранного варианта и 12/12 свежих отчётов по числу подсвеченных слов. Побед по размеченным фрагментам нет. На свежем D06 новый порядок выдвинул тематический форум без сохранённого тела и исключил PDF, который давал восемь подтверждённых слов. Содержание форума неизвестно; поэтому ноль в этом повторе не является предсказанием результата его живого чтения. Само вытеснение полезной страницы подтверждено. D08/D10 остались без подсветки в обоих порядках.

Изменились наборы загружаемых URL в 10/30 прежних и 5/12 свежих случаях; часть добавленных страниц не сохранена. Новых запросов поиска, внешних GET и моделей — **0**. Production не менялся. Четыре авторских теста подтверждают ограничение корня, русские токены, неизменность первого ключа и стабильность равных вторых ключей. Воспроизводимый скрипт — `scripts/probe_url_suffix_tiebreak.py`; полные частные результаты — `url-suffix-tiebreak-v1/comparison.json`. Финальные 70 и оба закрытых RFC не читались.
