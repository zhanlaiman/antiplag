# Материалы интернет-проверки · 100 случаев

11 ноября 2026 года собраны **30 документов для настройки и 70 для финальной проверки**. В обоих комплектах есть входные тексты, черновая разметка, снимки публикаций и сведения об их происхождении. Все 100 случаев ожидают ручной сверки. На настроечной части проведена диагностика выбора фраз, а пять документов также проверены через интернет. У двенадцати опубликованных входов можно открыть прежнюю публикацию и восстановить проверяемый текст по её снимку. В эту группу входят официальные параллельные версии документов и опубликованные тексты с цитатами. Статус описывает происхождение текста. Решение о наличии нарушения рецензент принимает отдельно. ## Что открыть на компьютере

Приватные материалы лежат в `data/private/web-evaluation/materials/`. Git игнорирует эту папку. Ссылки ниже работают из локальной копии проекта, в которой хранятся материалы.

- [Каталог 30 случаев](<../data/private/web-evaluation/materials/dev-30/КАТАЛОГ.md>) открывает входные тексты, пары выдержек, вопросы редактору и сведения об авторстве и лицензиях.
- [Настроечный архив](../data/private/web-evaluation/materials/dev-30.zip) содержит каталог, 30 входных текстов, ключ и 15 снимков с реестром. Введённый на сайте текст берите из папки `inputs`.
- [Финальный архив](../data/private/web-evaluation/materials/final-sealed.zip) содержит 70 отдельных входов, ключ, 62 снимка и итоговый реестр. Открывать комплект для прогона следует после фиксации настроек. Права локальных архивов `0600` дают доступ владельцу файла. ZIP сохранены без шифрования.
- [Протокол технической сверки](../data/private/web-evaluation/materials/materials-100-integrity.json) фиксирует состав обоих комплектов и результаты проверок. [Правила будущей оценки](EVALUATION_PROTOCOL.md) определяют порядок ручной проверки и последующего прогона.

## Проверка целостности

Каждый из 100 входных текстов прочитан как UTF-8 и проверен по SHA-256. Для 91 отмеченной пары сверены координаты из ключа и сохранённые слова с обеих сторон. У двенадцати опубликованных примеров дополнительно проверены координаты всего проверяемого текста в снимке публикации. В трёх настроечных случаях сохранены варианты текста — добавленное слово, регистр первой буквы и оформление кавычек. Их различия записаны в карточках D10, D11 и D13.

Между двумя частями обнаружено ноль пересечений по адресам публикаций, идентификаторам страниц и редакций Wikimedia в пределах домена, SHA-256 исходных и проверяемых текстов и идентификаторам размеченных семейств. Для проверки страниц использованы идентификаторы 13 страниц Wikimedia в настройочной части и 58 в финальной. Цифры относятся к этим проверенным признакам. Родство похожих публикаций, которое нельзя установить по идентификаторам, может дополнительно проверить рецензент.

Архивы распакованы в памяти, каждый элемент побайтно сверен с локальным файлом. Рядом лежат `dev-30.zip.sha256` и `final-sealed.zip.sha256` для повторной проверки при переносе.

Тексты получены через официальный MediaWiki TextExtracts API русской Википедии с разрешением перенаправлений. В приватных записях сохранены URL, авторство через историю правок, сведения о лицензии, время получения, идентификаторы страницы и редакции, ссылка на редакцию и SHA-256 точного текста.

API сообщает последнюю редакцию одновременно с извлечённым обычным текстом (`revision_binding: reported_latest_revision`). Тождество извлечения именно этой редакции отдельно не доказано; точный полученный снимок определяется хешем. Статьи свыше 200000 символов отклоняются с записью ошибки, без скрытой обрезки. Повторы страниц и текстов исключаются с записью ошибки.

Этот первоначальный пул резервировался только для настройки. На момент его сохранения финальные публикации ещё не были подобраны, а независимые тексты и переводы для проверки только предстояло собрать. Более поздняя сборка описана в начале документа.

В рамках сбора не выполнялись поисковые проверки Tavily, вызовы моделей или GPU; поисковый бюджет не изменялся.
