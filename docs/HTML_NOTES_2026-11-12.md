# HTML-сноски: независимое представление

**Принят недеструктивный вариант:** исходный текст страницы сохраняется, очищенный текст добавляется отдельным снимком той же физической страницы. В коде `Fetcher(semantic_notes=True)` включён по умолчанию. Основное извлечение остаётся `html-parser-v2-implied-ends`, дополнительное — `html-parser-v3-semantic-notes` с отдельной политикой доказательства. Правила PDF не изменены.

Старые подсветки, их идентификаторы и смещения сохраняются; новые точные совпадения добавляются только при увеличении покрытия. Перекрывающиеся слова считаются один раз. Исходные title/links сохраняются, второй снимок не считается ещё одной прочитанной страницей.

Проверены три сохранённых HTML на одинаковых байтах:

| Пример | Покрытие legacy → независимое представление | Контроль |
|---|---|---|
| Искусственная вставка A0008, «Фотография» | 9/10 → 10/10 содержательных слов | 140 сносок; исходные 1024 ссылки сохранены |
| D04: [URL «Пифагоровы штаны»](https://ru.wikipedia.org/wiki/%D0%9F%D0%B8%D1%84%D0%B0%D0%B3%D0%BE%D1%80%D0%BE%D0%B2%D1%8B_%D1%88%D1%82%D0%B0%D0%BD%D1%8B), заголовок «Теорема Пифагора» | 7/7 → 7/7 слов | Все 179 элементов MathML и 366 ссылок неизменны |
| РИА, другой издатель | 0 → 0 совпадений | Текст, 102 ссылки и 7 элементов textarea неизменны |

Два дополнительных контроля потребовали 2 вызова обычного Fetcher и 5 HTTP-запросов с robots/redirects: 0 поисковых API, 0 ₸. Для сравнения повторных загрузок не было.

Первая версия удаляла буквальные примеры внутри code/quote/math-контекстов: сохранены шесть контрпримеров, исправленных защитой предков. V3 добавила Unicode только в локальные идентификаторы `#cite_note`. Семь фиксированных искусственных фрагментов дали 63/70 → 70/70 слов; четыре пересекают заголовки и команды редактирования, поэтому не являются обычной прозой. Относительные и percent-encoded ссылки не расширялись; неоднозначная структура сохраняется.

**Отвергнутая замена текста:** копия с видимыми `[1][2]` теряла подсветку 12/12 → 9/12 токенов, включая слово «дней». Цитата с URL имела ту же потерю. На тех же реальных байтах независимое представление сохраняет 12/12 токенов и 10/10 содержательных слов в обоих случаях; вариант без номеров улучшает 9/10 → 10/10. Исходная регрессия сохранена как контроль.

На 34 известных случаях выполнены 68 фиксированных сравнений и 34 повтора очереди: потерь старых пар нет, добавлен полный A0008. Очереди, ZERO и ссылки в этих повторах неизменны. Неизвестный старый запрос Wiki в A0041 остаётся неизвестным в обоих вариантах. Это сохранённые данные, не новая интернет-проверка.

Публичные проверки: 28 тестов parser/Fetcher и 27 тестов независимого доказательства. Подделки, обход через PDF, лимит 200000 символов на страницу с представлением и неоднозначные снимки проверены отдельно.

Приватные доказательства: `dev-html-independent-view-replay-v1`, `semantic-notes-controls-v1`, `semantic-notes-cited-target-regression-v1` внутри `data/private/web-evaluation/`.
