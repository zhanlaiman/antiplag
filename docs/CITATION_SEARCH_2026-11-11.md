# Разбор D04 и D11

Более поздний полный прогон D04 с новой выдачей подтвердил все семь слов. [Новый отчёт и бюджет](D04_FRESH_CHECK_2026-11-11.md).

В рабочем сайте включён `hybrid-citation-v2`. Сохраняются прежние ограничения — до шести поисковых запросов и двенадцати попыток чтения страниц на документ, с прежним числом фраз для коротких текстов.

## Причины и изменения

У D11 равномерное окно захватывало авторский комментарий, а доли бюджета не хватало для второго характерного окна внутри цитаты. Теперь цитаты длиной от шести слов получают приоритет в характерной части бюджета. В поисковую фразу входят слова внутри кавычек.

В D04 вставка содержит короткое название с годом. Раньше оно проигрывало более длинному описанию школьной постановки. Теперь такое название может получить шестисловное окно с ближайшим контекстом года. Окно не пересекает границу предложения. Фразы строятся только из текста пользователя.

Это исправило попадание во вставку, но в живом поиске D04 всё ещё не подсветился. Поисковик вернул страницу оперы «Иванов Павел», где требуемого предложения нет. На этой странице есть ссылка «Пифагоровы штаны». Её подпись пересекается со словом «штаны» из документа пользователя. Переход привёл к тексту о теореме Пифагора и подтвердил все семь слов вставки.

Для этого добавлено чтение одной связанной страницы с каждого первоначального источника, если на нём нет дословного совпадения. Ссылка выбирается по словам подписи, встречающимся во входном документе. Навигационные и скрытые ссылки исключаются. Переход разрешён только в пределах того же сайта, повторные URL исключаются. Вложенные переходы не выполняются. Все попытки входят в общий предел двенадцати. Проверки публичных адресов, DNS и robots применяются обычным загрузчиком.

D11, D03 и D07 проверены с настоящим поиском. Для D04 сначала выполнен настоящий поиск с одной фразой, он дал нулевую подсветку. После изменения чтения связанных страниц использовали ту же сохранённую выдачу и заново получили страницы через штатную HTTP-очередь сайта. Повтор отмечен провайдером `tavily-saved-search-replay` и отдельным пояснением в отчёте. Такой повтор подтверждает переход от уже найденной страницы к выдержке. Новую выдачу поисковика для окончательного изменения ещё не проверяли.

D11 подсвечен с признаком оформленной цитаты. Два загруженных материала содержат одинаковую цитату, десять совпавших слов считаются один раз. Оригинальная страница Белинского из эталона в найденные страницы не вошла. D04 прочитан по ссылке с названием «Пифагоровы штаны», приводящей к тексту теоремы, тогда как в разметке записан основной адрес статьи. Все отчёты неполные, поскольку часть страниц недоступна.

На 30 настроечных документах новый выбор фраз захватил ≥6 совпадающих слов в 12 из 18 дословных участков. Предыдущий гибрид захватывал 10, равномерный поиск 2. Утраченных дословных захватов относительно предыдущего гибрида нет, добавлены D04 и D11. Суммарно запланировано по 46 фраз на вариант. На трёх самостоятельных контрольных текстах сопоставление с фиксированными снимками дало ноль подсветок. Этот локальный опыт проверяет выбор фраз и сопоставление, чтение ссылок измерено отдельно в повторе D04. [Таблица по каждому документу](baselines/web-query-citations-2026-11-11.md)

Разметка остаётся предварительной. Независимые 70 документов для финальной оценки не открывались для настройки. Более длинные цитаты, несколько названий в одном тексте и подписи ссылок требуют дальнейшей проверки на других материалах.

## Проверки и продолжение

Прошли 383 серверных теста и 55 интерфейсных. Добавлены проверки границ кавычек, датированных названий, Unicode-координат, исключения скрытых ссылок, одного перехода и общего предела загрузок. Стратегии `uniform-quoted-v1`, `distinctive-paragraph-v1` и `hybrid-paragraph-v1` доступны через `ISTOK_WEB_QUERY_STRATEGY`.

Для повторения локальной таблицы при наличии приватных dev-30 материалов выполнить `python3 scripts/compare_web_queries_offline.py --include-citations --output /tmp/istok-citations.json --table /tmp/istok-citations.md`. Эта команда не обращается к поисковику.

В этой серии выполнено шесть новых поисковых запросов. Ночной предел 24 достигнут, дополнительных поисковых запросов не отправляли. Для повтора D04 прочитаны открытые страницы. Бюджет 0 ₸, GPU не запускался. Счётчик Tavily ранее показывал 26 из 1000 бесплатных кредитов, обновление последних поисков в кабинете ещё не подтверждено.

Этот последующий прогон выполнен после разрешения владельца расширить бесплатный поисковый бюджет. Результат сохранён в отдельном отчёте, указанном в начале документа.
