# Проверка подсветки: 11 ноября 2026

Это локальные повторы и **искусственные** пары, не независимая оценка точности продукта. Финальные 70 случаев не открывались. Поисковых запросов и платных вызовов в этой проверке нет.

Исходный matcher — `lexical-v2-kind-aware-dedup` из `a5a9aac`; проверенный вариант — `lexical-v3-anchored-tails`. Дополнительные шесть независимых пар с переносами и контроль настоящего дефисного слова (`long-\nterm` ↔ `long-term`) проходят в `tests/test_matching_typography_controls.py`.

Переносы остаются воспроизводимым ограничением v3. Простое удаление всех дефисов на границе строки может повредить настоящим дефисным словам. Безопасный следующий эксперимент должен сохранять исходное сопоставление и добавлять альтернативное соединение только букв через один перенос строки, с исходными координатами выдержек. Разрыв `ве личины` в текстовом PDF D06 не содержит дефиса; его нельзя исправлять массовым удалением пробелов.

## Первая проверка незнакомого материала

До выбора v3 зарезервированы три официальные страницы: [SQLite](https://www.sqlite.org/whentouse.html), [NOAA](https://oceanservice.noaa.gov/facts/tides.html), [NASA](https://eclipse.gsfc.nasa.gov/SEhelp/safety2.html). Время резервирования — 11 ноября, 23:28:20 по Алматы. Обычный загрузчик сайта соблюдал robots.txt; сохранены URL, время и SHA текстов. Страницы не читались для выбора варианта. После выбора выполнена одна матрица искусственных вставок по 10/20/40 слов и независимых контрольных текстов. По результатам matcher не менялся.

На двух страницах с содержательным текстом (NASA и NOAA):

- 6 дословных вставок: 140 → 140 найденных слов из 140, все 6 полностью найдены.
- 6 вставок с одним добавленным словом: 108 → 120 из 140 исходных слов; полностью покрыто 0 → 3 из 6. Два коротких случая остаются без подсветки из-за минимальной длины опорного совпадения; ещё один упирается в границу предложения.
- 4 самостоятельных текста на ту же тему: 0 → 0 подсветок.

Полная матрица трёх страниц даёт 9 дословных вставок 210 → 210 / 210, 9 изменённых вставок 162 → 178 / 210 и 6 независимых контролей без подсветки. **SQLite выбрался из верхней навигации страницы**, потому что извлечённый текст разбит короткими строками. Поэтому его три вставки не включены в содержательный результат двух публикаций. Ошибка подготовки выборки произошла до вызовов matcher; возобновление использовало тот же заранее записанный SHA варианта. Не называть это повторной настройкой по holdout.

Полные частные артефакты: `data/private/web-evaluation/matcher-validation-2026-11-11.json`, `matcher-unfamiliar-holdout/reservation.json`, `matcher-unfamiliar-holdout/first-use.json`. Исходные снимки и выдержки в Git не включаются.

Повтор локальной проверки известных примеров:

```sh

python3 -m unittest discover -s tests -p test_matching_typography_controls.py -v
```

## Следующее отдельное изменение: переносы строк

После завершения первой проверки v3 отдельно добавлен `lexical-v4-line-wrap-variants`. Он сохраняет исходные токены и дополнительно проверяет вариант соединения букв через дефис и ровно один перенос строки. Выдержки по-прежнему берутся из исходных строк с исходными координатами. Проверка достоверности exact в offline scorer использует ту же ограниченную альтернативу; произвольные пробелы и границы абзацев не соединяются.

Повтор **v3 → v4** на тех же 30 отчётах не изменил ни одной подсветки. D04 сохранил семь слов. На 17 искусственных переносах: 235 → 269 из 269 исходных слов, полностью покрыто 0 → 17 случаев из 17. Ни одна из остальных 102 искусственных пар не потеряла дословных слов. Новых недостоверных exact-выдержек нет. Шесть независимых тематических пар остались без подсветки; дополнительные шесть независимых пар с переносами и настоящий дефисный составной термин также прошли.

Это подтверждённое локальное исправление искусственного воспроизводимого дефекта. Прибавки на исходных 30 документах от него нет. Незнакомые страницы не использовались для настройки v4 и заново не выдаются за его независимую первую проверку. D06 с разрывом `ве личины` остаётся ограничением.

Артефакт: `data/private/web-evaluation/matcher-line-wrap-v4-vs-v3.json`. Воспроизведение:

```sh
python3 scripts/validate_matcher_variants.py --baseline adcadb8 --output data/private/web-evaluation/matcher-line-wrap-repeat.json
```

Дополнительный искусственный контрпример выявил предел двух глобальных вариантов. В паре `Scientists measured long-term changes in extremely distant galaxies.` и `Scientists measured long-\nterm changes in ex-\ntremely distant galaxies.` нужно сохранить настоящий дефис первого слова и убрать перенос второго. v4 находит 6 из 9 слов: исходный вариант сохраняет первый термин, соединённый вариант исправляет второй, но одновременно склеивает первый в `longterm`. Ни один вариант не даёт полного выравнивания. Случай сохранён в `docs/baselines/mixed-line-wrap-limitation.json` с обеими строками и ожидаемым полным покрытием. Он не входит в 17 простых переносов и не скрыт из их знаменателя. Правила сопоставления после этой проверки не менялись. Возможное продолжение — выбор соединения на каждом переносе внутри ограниченного выравнивания; массово перебирать все сочетания переносов не следует.

## Устранён повторный разбор длинного совпадения

Версия `lexical-v4.1-cached-anchors` вычисляет длину опорного дословного совпадения один раз перед проверкой окон предложений. Раньше одна и та же длинная выдержка разбиралась заново для каждого предложения. На авторских текстах из 20 и 80 предложений число таких разборов уменьшилось с 20/80 до одного; отдельный тест проверяет именно количество вызовов, без ненадёжного ограничения по времени.

Все массивы подсветок на 30 сохранённых отчётах и 119 искусственных парах остались неизменными: потерь, новых совпадений и недостоверных выдержек нет. Один локальный искусственный тест точной копии на 199 818 знаков и 1 959 предложений завершился за 0,776 с, пик памяти 52,73 MiB. Исходный вариант на том же шаблоне остановлен после более 60 с; точного времени его завершения нет. Это микропроверка matcher без поиска и загрузок, не обещание времени всей проверки сайта.

Артефакты: `data/private/web-evaluation/matcher-anchor-cache-v4.1.json` и `matcher-anchor-cache-stress.json`. Полный серверный набор после исправления: 453 теста, все проходят; интерфейсный Node-набор: 55, все проходят.
