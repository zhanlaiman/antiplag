# Статус решения редактора после сохранения

Исправление R2 Low из независимой проверки `prospective-f56-929-b5f155d`, отдельным коммитом поверх SEO-ветки. Зелёный дизайн, расчёт уникальности, серверные данные и API не меняются. Публикация в это изменение не входит; расходы — 0 ₸.

## Причина и поведение

Если сохранить решение по совпадению A и до ответа сервера выбрать B, решение сохранялось на сервере и в памяти, но сохранённая DOM-карточка A оставалась без значка. Повторный выбор A перерисовывал только сравнение, поэтому значок не появлялся.

Теперь ответ обновляет значок нужной карточки непосредственно в существующем списке. Подтверждение и отклонение показывают соответствующий статус; возврат на проверку убирает значок. Для выбранного совпадения обновляются пояснение, действие возврата и сообщение о сохранении. Список, карточки и поле комментария не пересоздаются. Новые правки комментария сохраняются как черновик. Ответ от другого отчёта не изменяет текущий отчёт, даже если ID совпадения одинаковый.

Значки и сообщение о сохранении имеют `role="status"`; `aria-pressed` продолжает отражать выбранное совпадение.

## Проверка

| Сценарий | Результат |
| --- | --- |
| Задержанный ответ A → выбор B → ответ → возврат A | Значок A обновлён ещё при выбранном B; комментарий и решение сохранены в локальной SQLite |
| Последовательные подтверждение / отклонение / возврат | Текст и класс значка корректны, возврат убирает значок, DOM списка и карточки сохранён |
| Уход и возврат к A во время сохранения, затем новая правка | Новая правка и фокус поля сохранены; показано сообщение о несохранённых изменениях |
| Переход в другой отчёт с тем же ID совпадения | Старое решение сохранено только в исходном отчёте; новый отчёт не изменён |
| Длинный отчёт: 220 107 символов, 2001 совпадение | Карточки сохраняют идентичность; ширины 320, 375, 768, 1024, 1440 без горизонтального переполнения |
