# Четыре недоступные страницы D04

11 ноября 2026 года отдельно воспроизведены ошибки четырёх страниц из нового живого отчёта D04. Диагностика использовала обычный загрузчик с записью этапов соединения и безопасного набора HTTP-заголовков. Сохранены адреса DNS, выбранный IP, время этапов, статусы и перенаправления. Поисковые API и модели не вызывались.

## Изменения загрузчика

`Content-Encoding: none` обрабатывается как несжатое содержимое. Прежние ограничения размера и проверки кодировки применяются к полученным байтам. Повреждённое сжатое содержимое с таким заголовком не считается прочитанным HTML.

Для robots.txt поддерживаются до пяти перенаправлений, включая смену хоста. На каждом шаге проверяются публичность адреса и DNS, а для HTTPS проверяется сертификат. Полученные правила относятся к исходному сайту, кэш также привязан к нему. Это соответствует порядку перенаправлений robots.txt. [RFC 9309, раздел 2.3.1.2](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.3.1.2)

Ошибка сервера при получении robots.txt теперь обозначается как невозможность получить правила. Запрет из полученных правил обозначается отдельно. Сообщения веб-отчёта различают тайм-аут, запрет сайта и неподдерживаемое сжатие.

Лимит страниц по-прежнему равен двенадцати попыткам. Тайм-аут отдельного запроса равен восьми секундам, общий срок загрузки одной страницы — двадцати. Сторонние прокси, платные услуги и новые зависимости не подключались.

## Повтор D04

Повтор проведён через штатную HTTP-очередь на сохранённой выдаче предыдущего живого прогона. Из неё исключён URL, ранее обнаруженный переходом по ссылке, чтобы он снова находился самим алгоритмом. Все страницы заново получены обычным загрузчиком.

Из четырёх первоначально недоступных страниц восстановлена одна — газетная статья. Четвёртая прочитанная страница появилась из дополнительной ссылки в этой статье. Число ошибок сократилось на одну. Полнота остаётся частичной из-за двух тайм-аутов LiveJournal и запрета LinkedIn.

Полные трассы и полученный снимок статьи сохранены в `data/private/web-evaluation/fetch-recovery/`, полный отчёт повтора — `data/private/web-evaluation/night-live/D04-fetch-recovery-replay.json`. Локальный месячный журнал поисковых попыток остался равен 38. Новых запросов к платным API и GPU не было.

Прошли 389 серверных тестов и 55 интерфейсных. Регрессии покрывают несжатый HTML с заголовком none, предел размера, неправильные байты, перенаправления robots между хостами, кэш исходного сайта, запреты из правил, приватные адреса и остановку после пяти перенаправлений. Рабочий сайт перезапущен с исправлениями.

Для оставшихся двух адресов LiveJournal следующий осмысленный опыт — повтор после изменения доступности сети или сервиса. Полученный запрет LinkedIn сохранён как ограничение охвата.
