# HTML: необязательные закрывающие теги и ложная глубина

Общее исправление перенесено в рабочее дерево с разрешения root; коммит и полный общий прогон остаются за root. Версия извлечения — `html-parser-v2-implied-ends`. CSS Overview помечен `used_for_tuning` для HTML до разбора структуры и исключён из полностью незнакомой проверки. Содержание RFC9309 и RFC1149 не открывалось. Использовались только сохранённые CSS-байты. После разрешения root две короткие выдержки сверены глазами в локальной браузерной копии с блокировкой внешних ресурсов; RFC-источники не открывались.

На последних 30 DEV-отчётах `html_too_complex` встречается **1 раз в 1/30 документе**, D29. Содержимое той отказавшей страницы не сохранено; связь ошибки с необязательными тегами для неё не доказана. Этот URL не совпадает с размеченным исходным URL D29. Подтверждённого восстановления заимствования на DEV этим опытом нет.

Ошибки чтения сами по себе не являются числом потерянных размеченных фрагментов. По подтверждённому влиянию эта причина ниже уже найденных потерь очереди и PDF D06.

На CSS ошибка воспроизводится: после 317 начальных тегов стек достигает 128. В нём 95 `td`, 21 `tr`, пять `th`: соседние ячейки и строки ошибочно накоплены как предки. Во всём документе только 590 узлов; наивный стек достигает 201. Дополнительно отсутствует явное закрытие `head`, из-за чего существующий фильтр продолжает считать `body` скрытой частью заголовка.

Пропуск некоторых закрывающих тегов предусмотрен HTML: среди них `head`, `p`, `li`, `dt/dd` и табличные ячейки/строки при определённых следующих элементах. [HTML Standard: optional tags](https://html.spec.whatwg.org/multipage/syntax.html#optional-tags). Правила разбора завершают режим `head` перед обработкой тела; табличные режимы закрывают текущую ячейку и возвращаются к строке/секции с учётом границ таблицы. [Режим head](https://html.spec.whatwg.org/multipage/parsing.html#parsing-main-inhead), [режим ячейки](https://html.spec.whatwg.org/multipage/parsing.html#parsing-main-intd).

Исправление: до прежней проверки глубины завершать только применимый необязательный элемент в своей области — ячейку/строку внутри текущей таблицы, пункт внутри текущего списка, `dt/dd` внутри `dl`, абзац перед соответствующим блоком; при явном `body` завершать незакрытый `head`. Границы `template/nav/aside` и остальных исключаемых контейнеров не пересекаются. Скрытые обычные `div/span` также останавливают поиск закрываемого предка; скрытая ячейка или пункт сами могут завершаться. Сохранять окончания ссылок и пробельную границу закрываемого блока. `td/th` также должны давать границу слова: отдельный авторский тест обнаружил существующее склеивание соседних ячеек в компактном HTML.

Прототип `scripts/probe_html_optional_closings.py` сохраняет пределы 128 и 50 000. На тех же CSS-байтах обрабатывает 590 узлов с максимальным стеком **8**; видимые символы только подсчитаны (7112), содержимое не выведено и не оценено как свидетельство совпадения. Это ограниченная обработка характерных пропусков, не реализация всего алгоритма HTML5. В частности, режимы вставки браузера и восстановление произвольной испорченной разметки не воспроизводятся полностью.

Все **17 авторских тестов** и **24 существующих теста Fetcher** проходят: незакрытый `head`; длинная плоская таблица; обычные и вложенные списки/таблицы; настоящая чрезмерная вложенность; предел узлов; скрытый родитель, `nav`, `aside`, `template`; границы абзацев, ячеек и ссылок. Прежние защиты от глубокой реальной вложенности срабатывают. Приватные доказательства — `query-unfamiliar-reserved-v2/html-structure.json`, `optional-closing-structure-probe.json`, `html-guard-frequency.json`.

Проверено точное сохранение нормализованного текста, ссылок и заголовка трёх корректных авторских страниц по сравнению с замороженным прежним парсером. На сохранённом CSS получено 5057 символов нормализованного текста; две десятисловные выдержки совпадают с видимыми первыми абзацами. Распознанные скрытые блоки, `nav/aside/template`, стили и формы не раскрываются. Существующее ограничение: навигационный `div id="banner"` без роли или тега `nav` остаётся в тексте; фильтр этим исправлением не расширялся. Общий набор тестов root запустит перед коммитом. Новых внешних GET или поисковых запросов для переноса и проверки не было; исходные резервирования не повторялись.
