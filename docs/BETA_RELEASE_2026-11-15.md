Это идентификаторы, включая исторические/тестовые записи, не число людей или посещений. Единственный зарегистрированный QA-аккаунт заблокирован. Дневные показатели используют UTC; знаки и ошибки с подписью «на странице» относятся к текущей странице. Удобное сопоставление логина с техническими ID ещё требует улучшения.
- Pool: добавление и проверка ключа, безопасное включение/отключение/замена, серверное хранение секретов, квоты и причины недоступности. У задания закреплён неизменный ключ; смена ключей не подменяет уже принятое задание.
- Автоматический backend для SerpApi, Serper, Tavily и Exa с новым явным согласием. Переключение разрешено по подтверждённому исчерпанию; неизвестный исход не означает бесплатную попытку у следующего провайдера. Serper/Exa прошли синтетические протокольные проверки, реальные поисковые smoke для них в этом этапе не выполнялись.
- Тёмная синяя тема dashboard/Pool, иконки Истока для браузеров и телефона. Публичный зелёный дизайн сохранён; независимая прокрутка списка источников включена ранее в интегрированное ядро.
