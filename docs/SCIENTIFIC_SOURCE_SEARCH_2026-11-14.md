# Пропуск скопированной научной статьи

Владелец прислал текст публикации СибАК и сообщил о нулевом результате. Сохранённый отчёт содержит 5 790 знаков без библиографической ссылки из последнего сообщения; прочитано 19 страниц, искомая статья не была обнаружена. Первая копия отчёта сохраняется приватно и не подменяется результатами диагностики.

Исходная HTML-статья найдена отдельно через название и автора. Обычный Fetcher Истока читает её; локальное сравнение даёт 692/692 исходных слова. Это проверка с известным источником и подтверждение потери при поиске. Автоматическое обнаружение этим не доказано. Ссылка на PDF сборника отдельно отклонена по robots.txt; ограничения не обходились.

Кандидат меняет только один параметр Tavily: `exact_match: true`. По [официальной документации](https://docs.tavily.com/documentation/api-reference/endpoint/search) этот параметр требует наличия заключённых в кавычки фраз, исключая смысловые варианты. Прежний запрос с кавычками не включал его. Изменение не добавляет эталонный URL, домен, название или автора в план. Число, текст и границы шести фраз сохраняются; Basic, пять результатов, запрет автоматического advanced, контроль usage и месячные бюджеты сохраняются. Сниппеты остаются подсказками поиска, совпадения считаются только по прочитанным страницам.

Параметр реализован только как opt-in конструктора `TavilySearch(..., exact_match=True)`. По умолчанию прежнее поведение; runtime v7 не переключён. Отчёт записывает `provider_query_policy`. Тип параметра и форма запроса проверяются до расхода квоты. Модульные тесты сравнивают сериализованные Basic-запросы: различается ровно один флаг; модели, платный режим и новая выдача не запускаются.

До живой проверки фиксируются настоящий проверенный текст владельца без библиографии, прежний положительный контроль короткой вставки и прежний отрицательный контроль. Они диагностические, а не независимая оценка точности. Допускаются один парный прежний запрос, 12 запросов для трёх полных локальных проверок и до 6 для публичного подтверждения только после положительных результатов. Всего не более 20 новых основных попыток; неизвестный исход занимает слот и не повторяется. Этот этап требует отдельного согласования после исчерпанных прежних 120. Счётчики сайта и провайдера не сбрасываются и не повышаются.

Пока не выполнено подтверждение источника через обычную поисковую цепочку, исправление не считается проверенным и режим не включается в production. Условные 692/692 не выдаются за восстановленную точность интернет-проверки.
