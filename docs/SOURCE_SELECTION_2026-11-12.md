# Выбор страниц и связанные переходы

Сравнение использует последнюю сохранённую выдачу каждого из D01–D30 и доступные снимки страниц. Финальные 70 и QH не использовались. Алгоритм получает URL, порядок результатов и проверяемый текст; ожидаемый URL передаётся только оценщику.

Исходный порядок — `hybrid-domain-query-v2`: шесть первых мест распределяются по доменам, остальные чередуют ранги разных запросов. Нужная страница D09 оказалась ниже двенадцатого места. В D30 она была девятой, но пять связанных переходов вытеснили её до чтения.

Новый порядок `hybrid-input-path-v3` сохраняет этот порядок при равных оценках и поднимает URL, в декодированном пути которых есть слова документа длиной от четырёх знаков. Цифровые слова, домен, query и fragment не дают оценки. Никаких эталонных URL или текстов источников для ранжирования нет.

Для связанных переходов проверены по очереди три ограничения. Общий лимит чтения остаётся двенадцать, рекурсивных переходов нет.

1. Один переход на весь документ отклонён: при свободной очереди пропадает второй полезный источник.
2. Одна замена только в полной очереди сохраняет свободные переходы, но всё ещё теряет вторую полезную страницу при полной очереди.
3. `productive-priority-v1`: сначала разрешена одна приоритетная замена. Новая замена разрешается, только если предыдущая связанная страница добавила новые подтверждённые exact-слова. Ошибка загрузки, повтор уже покрытых слов или отсутствие совпадений бюджет не возвращают. Добавление ссылок в свободную очередь не ограничивается этим правилом.

| Повтор на одинаковом кеше | Исходный порядок | Только продуктивный бюджет | Путь + продуктивный бюджет |
| --- | ---: | ---: | ---: |
| Полностью покрытые скопированные фрагменты | 13/18 | 13/18 | 14/18 |
| Подтверждённые скопированные слова | 243/283 | 243/283 | 248/283 |
| Ожидаемые URL прочитаны | 9/28 | 10/28 | 11/28 |
| Документы без прочитанных страниц | 0/30 | 0/30 | 0/30 |

Это 18 буквальных фрагментов в 16 документах; 28 пар «документ — источник» относятся ко всем 30 документам. Вставленное слово D10 не входит в скопированный знаменатель. Изменений фактически отправленных поисковых фраз и получения ссылок здесь нет.

D09 восстанавливает пять слов, до 29/29; D30 получает ожидаемую страницу, но смысловая связь не устанавливается буквальным режимом. D04 сохраняет семь контрольных слов, D20 — обе вставки, 25 слов. В D12 пропадает одна дублирующая ссылка dslov на цитату; полные 55 слов проверяемого отрывка по FEB остаются. Эту потерю источника нельзя скрывать за неизменным покрытием слов.

Известный проигрыш нового бюджета: при полной очереди первый бесполезный переход может закрыть поздний полезный переход. В авторском примере старый вариант покрывает 9 слов, новый — 0. Пример сохранён; правило после него не подгонялось. Два полезных связанных источника при свободной и при полной очереди сохраняют 18/18 слов. Это ограниченный компромисс распределения двенадцати загрузок, не гарантия нахождения любой пары источников.

В исходных свежих отчётах не сохранялись все HTML-ссылки. Для D20 один раз заново прочитан настоящий родитель DigitalPhotoWiki: SHA текста совпал с прежним, сохранены 235 настоящих ссылок и новое время. Затем текущий повтор воспроизвёл число найденных слов исходных свежих отчётов в 30/30 случаях. Однако это не делает кеш полным: у нового порядка есть 176 попыток без сохранённого текста и 38 страниц без полной информации о ссылках. В их числе исторические отказы; неизвестное содержимое не объявляется проверенным. Все повторы помечены частичными.

Производственный код отдельно воспроизвёл выбранные диагностические результаты во всех 30 случаях: порядок загрузок, источники, выдержки и скопированные слова. Это **проверено локально, свежая выдача ещё не проверена**. Новый путь пока включается явно, стратегия по умолчанию остаётся BALANCED до подтверждения свежим прогоном. Новых поисковых запросов в этом исследовании нет; одна прямая загрузка страницы, 0 ₸.
