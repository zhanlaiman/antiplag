# Требования по возможностям платной версии text.ru

Ориентир — заявленные возможности платного продукта и соответствующие рабочие сценарии. Бесплатные гостевые результаты не используются для вывода о качестве платной проверки. Платные проверки и подписки не покупались. Предыдущий искусственный эксперимент сохранён как исторический артефакт, а не как оценка платного продукта.

Публичные страницы прочитаны 13 ноября 2026. Это описание поставщика; отдельное качество платного алгоритма на этих страницах экспериментально не подтверждено.

| Требование | Что заявлено | Исток в этом релизе | Проверяемый критерий / пробел |
| --- | --- | --- | --- |
| Проверить текст и перейти к источнику | Интернет-проверка, найденные заимствования | Есть; ограниченный поиск, подсветка, две выдержки и URL | Сохраняются точные доказательства; без прочитанных страниц уникальность не установлена |
| Устойчивость к изменённым вставкам | В общем описании названы перестановки, добавленные слова и формы слов | Частично: дословные и лексически близкие фрагменты; пересказы/переводы не дают надёжного процента | Полного соответствия нет; не обещать равную точность или полный охват |
| Документы | TXT, DOC, DOCX, PDF, ODT, RTF, HTML | TXT/MD, DOC, DOCX, текстовый PDF, ODT, RTF и HTML | DOCX/PDF до 1 МиБ, PDF до 40 страниц, без OCR; повреждения/сканы/расширение ZIP/порядок текста проверены. DOC/ODT/RTF/HTML добавлены с проверками повреждений и ограничениями; добавлен пакет до пяти документов с предварительным просмотром и отдельными отчётами; ID сохраняются до отправки, после перезагрузки новые проверки не запускаются автоматически |
| Архив и повторное открытие | История проверок и возврат к результатам | Есть; гостевое и постоянное пространство владельца | История, reload, экспорт HTML/JSON, корзина/восстановление, личный ZIP с данными и изоляция; общего восстановления гостевого доступа нет |
| Очередь и скорость | Приоритет оплаченных проверок | Ограниченная фоновая очередь, без платных приоритетов | Три одновременных задания завершаются последовательно. Массовая производительность не подтверждена |
| Большие ежедневные объёмы | ПРО предлагает 25/100/150 тыс. символов в сутки по уровням | Лимиты бесплатной беты остаются 10000 за текст, 6 проверок/браузер/сутки и 180 основных запросов/месяц | Не поднимать ради табличного совпадения: при бюджете 0 это ограничение ресурса |
| Проверка Telegram | Доступна в ПРО | Исключено пользователем из текущего объёма | Для законного индекса нужны отдельные источники, сбор и эксплуатация; поиск открытых веб-страниц не равен индексу Telegram |
| Проверка сайта | Включена среди форматов ПРО | Добавлена ограниченная загрузка до трёх публичных страниц в пакет, затем отдельная проверка каждой | Pinned DNS, robots.txt, блокировка внутренних адресов, согласие и отдельные лимиты. Собственный исходный хост исключается из совпадений. Полный обход большого сайта не реализован |
| API клиента | Доступен в старших тарифах; получение ID, результата и статуса | Добавлен API v1 с ключами владельца: отчёты, источники, очередь и остатки | Ограниченные разрешения, срок до 90 дней, отзыв, только хеш на сервере; общий поисковый лимит и idempotency сохранены. HTTP проверены права, изоляция, restart/replay и отзыв. Дата публикации фиксируется в HANDOFF |
| Статистика и частоты | Число символов/слов, ключи и их формы | Счётчики и частые словоформы в браузере; однозначные словарные основы Hunspell на сервере | Проверены Unicode/регистр/смешанные алфавиты. Словарные формы объединяются только при единственной основе; неоднозначные остаются отдельно. Полного грамматического/семантического разбора нет |
| Смешение алфавитов | Поиск слов со смешанной раскладкой | Добавлен контроль кириллицы+латиницы | Пример «стoл» с латинской o обнаруживается; статистика не меняет исходный текст и процент совпадений |
| «Вода» и заспамленность | Свои показатели анализа текста | Добавлены собственные доли слов из открытого служебного списка, повторных содержательных вхождений и самой частой формы | Формулы и знаменатели видны в интерфейсе; частое слово выделяется в редакторе по нажатию. Это ориентиры для редактирования, не оценка смысла, рейтинга или сопоставимый процент конкурента. [Определения и проверка](TEXT_STATISTICS_2026-11-14.md) |
| Орфография/грамматика/пунктуация | Отдельный инструмент с исправлениями | Добавлен русский словарь Hunspell и правила пробелов, повторов, пунктуации и нескольких грамматических конструкций | Ручное применение каждой подсказки, личный словарь, UTF-16 диапазоны, отклонение устаревших правок. Имена/термины не объявляются гарантированными ошибками; полной грамматики нет |
| Нейроинструменты | ПРО даёт ограниченные нейросимволы | Добавлен опциональный корректор Qwen3.5:9b на включённых кредитах Modal | Отдельное согласие, 3000 знаков, 2 запуска/пространство/день, 3/сайт/день, 10/месяц. Публичные предложение, ручная правка после emoji, reload, JSON и восстановление из копии проверены. Первоначальный timeout сохранён и учтён; доступность GPU и полная грамматика не гарантируются. Словарь работает независимо. [Проверка](QWEN_CORRECTOR_2026-11-14.md) |
| Поддержка и аккаунты | Тарифные приоритеты и постоянный аккаунт | Есть один владелец и гости | Общая регистрация, восстановление и платежи остаются отдельным этапом по исходному поручению |

Источники требований: [ПРО-аккаунт](https://text.ru/pro), [ПРО-пакет](https://text.ru/pack), [документы](https://text.ru/doc-check), [API](https://text.ru/api-check/manual), [описание алгоритма](https://text.ru/antiplagiat), [анализ текста](https://text.ru/seo), [правописание](https://text.ru/spelling). Орфография и SEO перечислены как связанные инструменты, а не как доказательство эксклюзивности платного тарифа.

В текущем цикле закрываются надёжность проверки, работа с документами, базовая статистика, история и эксплуатация. Соответствие всей платной версии не заявляется. Клиентский API, основные форматы, пакет, корзина и восстановление реализованы. Покрытие коротких вставок проверяется отдельно от остальных функций: [новая проверка](QUALITY_SHORT_PARAGRAPHS_2026-11-14.md). Полный обход сайтов, общая регистрация и восстановление гостей, постоянное удаление и полная грамматика остаются дальнейшими этапами. Telegram исключён пользователем; нейроинструменты используют ограниченный подтверждённый ресурс.

Продолжение по поручению владельца: панель «Мои данные», owner-only общая статистика без чужих текстов, корзина, восстановление, полный ZIP и личный словарь опубликованы с кодом 02d8f02. Новые возможности описаны в DATA_AND_CORRECTOR_2026-11-13.md. Telegram исключён. Прежний запрет GPU изменён явным разрешением владельца; Qwen проверен отдельно, без установки моделей на Mac. API опубликован после отдельной проверки; дальнейшие изменения требуют такой же проверки; точный статус и хеши — в HANDOFF.
