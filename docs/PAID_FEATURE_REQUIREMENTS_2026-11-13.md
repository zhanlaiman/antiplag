# Требования по возможностям платной версии text.ru

Ориентир — заявленные возможности платного продукта и соответствующие рабочие сценарии. Бесплатные гостевые результаты не используются для вывода о качестве платной проверки. Платные проверки и подписки не покупались. Предыдущий искусственный эксперимент сохранён как исторический артефакт, а не как оценка платного продукта.

Публичные страницы прочитаны 13 ноября 2026. Это описание поставщика; отдельное качество платного алгоритма на этих страницах экспериментально не подтверждено.

Источники требований: [ПРО-аккаунт](https://text.ru/pro), [ПРО-пакет](https://text.ru/pack), [документы](https://text.ru/doc-check), [API](https://text.ru/api-check/manual), [описание алгоритма](https://text.ru/antiplagiat), [анализ текста](https://text.ru/seo), [правописание](https://text.ru/spelling). Орфография и SEO перечислены как связанные инструменты, а не как доказательство эксклюзивности платного тарифа.

В текущем цикле закрываются надёжность проверки, работа с документами, базовая статистика, история и эксплуатация. Соответствие всей платной версии не заявляется. Дальнейший план по требованиям: (1) улучшать покрытие коротких вставок на раздельной выборке; (2) полный жизненный цикл удаления/восстановления; (3) клиентский API и аккаунты; (4) остальные форматы/пакетные задачи; (5) полноценный корректор и морфологический анализ; (6) отдельное законное покрытие Telegram и нейроинструменты при подходящем ресурсе.

Продолжение по поручению владельца: панель «Мои данные», owner-only общая статистика без чужих текстов, корзина, восстановление, полный ZIP и личный словарь опубликованы с кодом02d8f02. Новые возможности описаны в DATA_AND_CORRECTOR_2026-11-13.md. Telegram исключён. Прежний запрет GPU изменён явным разрешением владельца; Qwen проверяется отдельно, без установки моделей наMac. API и дальнейшие изменения проходят отдельную проверку перед публикацией; точный статус и хеши — в HANDOFF.
