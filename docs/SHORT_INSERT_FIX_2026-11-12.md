Теперь исключается только служебный `span` с точным токеном класса `mw-editsection`; обычные слова «править код» сохраняются. На одинаковых сохранённых HTML-байтах восстановлены последние два слова. Порог сопоставления не снижен.

Первый вариант — перенести полную десятисловную фразу без сокращения — отклонён: для неё уже был сохранён пустой ответ Wikipedia. Дополнительного запроса для этой гипотезы не делали.
