# D06: слово восстановлено локально, небезопасные варианты отклонены

[Сохранённый отчёт D06 с семью из восьми слов](http://127.0.0.1:8766/#check/52191c533cd3a27a84026e90530f03be) показывает сохраняющееся ограничение рабочего PDF-парсера. В PDF УрФУ слово «величины» извлекается как два слова. На изображении страницы 4 оно напечатано слитно. Новых поисковых запросов в этой диагностике нет; рабочий код не изменён.

Проверены три уже встречавшихся открытых PDF: методические указания УрФУ из D06, материал о фотографии из D20 и разворот о шрифтах из D16. Сырых файлов в прежних результатах не было: обычный обработчик их не сохраняет. Выполнено ровно три обычные загрузки через `Fetcher`, с проверкой robots, адресов и прежними ограничениями. Байты перехвачены временной обёрткой перед штатным извлечением; повторных загрузок нет. Размеры — 633383, 977300 и 485629 байт, страниц — 20, 14 и 4. Все три новых результата `plain` побайтно совпали с прежними сохранёнными текстовыми снимками.

Каждый режим разбирал **одни и те же байты** в отдельном процессе: не более 5 секунд, 40 страниц, 1 MiB входа, 200000 извлечённых символов и прежний предел памяти 512 MiB. Сеть и запуск программ из рабочего процесса запрещены. Зависимости и модели не устанавливались. Для `plain` и `layout` использован установленный `pypdf==7.0.1`; поведенческое изменение одно — `page.extract_text(extraction_mode="layout")`. В обоих клонах добавлены только диагностические длины страниц. Все шесть разборов завершились за 0,26–0,62 секунды.

| Проверка | `plain` → `layout` | Объём |
| --- | ---: | --- |
| Нужная вставка D06 | 7/8 → 8/8 слов | Один размеченный фрагмент |
| Полностью сохранённые буквальные контроли | 9/9 → 4/9 | По три искусственные выдержки из каждого прежнего PDF-снимка |
| Символы без пробелов, отсутствующие относительно `plain` | 0 → 803 | D06; без учёта изменений пробелов |
| Авторский текст на ту же тему без копии | 0 → 0 подсветок | Три пары с PDF, 35 слов авторского текста |
| Независимый исходный D16 | 0 → 0 подсветок | Один настроечный документ |
| Визуально переписанная настоящая фраза D16 | 8/8 → 0/8 слов | Один фрагмент со страницы 3 |

Среди 803 недостающих символов D06 много математических обозначений. В D16 режим `layout` также соединяет самостоятельные слова и перемешивает подписи образцов с параллельными колонками. Настоящая восьмисловная фраза проверена по изображению, поэтому её потеря не объясняется случайным выбором испорченного старого текста. Простая замена режима отклонена.

## Два представления того же PDF

Отдельно проверено сохранение `plain` основным и добавление `layout` как самостоятельного представления того же файла. Совпадения вычислялись для каждого представления отдельно, затем объединялись только позиции слов проверяемого документа. Тексты представлений не склеивались.

Такое объединение восстанавливает D06 до 8/8 слов и сохраняет все 9/9 прежних буквальных контролей, а также настоящую фразу D16. Однако оно добавляет ошибочное дословное свидетельство в специальных искусственных проверках:

| Контроль по исходному изображению D16 | `plain` | `layout` | Объединение |
| --- | ---: | ---: | ---: |
| Искусственно слитное «потолщине» внутри фразы | 6/9 слов, слитное слово не выделено | 9/9, слитное слово выделено | Сохраняет ошибочную подсветку |
| Искусственно слитное «изтвердого» внутри фразы | 6/7 слов, слитное слово не выделено | 6/7, слитное слово выделено | 7/7 со слитным словом |
| Фраза из частей двух параллельных колонок | 0/8 слов | 8/8 | 8/8 |

В первых двух случаях остальные слова частично являются настоящей цитатой; ошибочен добавленный дословный статус искусственно соединённого слова. На изображении страницы 4 видны раздельные слова. В третьем случае исходное изображение страницы 3 подтверждает две разные колонки. Эти три проверки специально созданы для поиска ошибок и не являются оценкой частоты ложных подсветок на обычных документах. Неотфильтрованное объединение `plain + layout` тоже отклонено.

## Один следующий парсер без установки

На тех же трёх файлах локально проверен уже имеющийся в комплекте Codex `pypdfium2==5.14.0`, метод `get_textpage().get_text_range()`. Он работал в отдельном процессе с теми же пределами и отключённой сетью. Время — 0,12–0,21 секунды на файл; новых загрузок и поисков нет.

PDFium восстановил D06 до 8/8 слов и не повторил две слитные ошибки и склейку колонок из таблицы. Авторские отрицательные пары остались без подсветок. Но замена основного парсера также не готова: полностью прошли 8/9 прежних буквальных контролей; настоящая визуально проверенная фраза D16 дала 0/8. Парсер разносит её перенос по отдельным строкам. Дополнительно 4, 2 и 62 дефиса соответственно заменены на несимвол Unicode `U+FFFE`. Это отдельный дефект представления, его исправление не включалось в опыт. PDFium как замена отклонён. Возможное дополнительное представление потребовало бы отдельной проверки границ и недопустимых символов.

Для отдельного представления PDFium проведён следующий локальный опыт: исходные совпадения `plain` сохраняются, а дополнительное совпадение отклоняется при несимволе Unicode или суррогате в любой из двух выдержек. Границы дополнительной выдержки также сверяются с сохранённым текстом её представления. Подмены дефисов и исправления слов не выполняются. D06 даёт 8/8 слов, два дополнительных совпадения контрольных выдержек отсеяны фильтром. Все 9/9 прежних контролей сохранены по построению объединения; это не испытание интеграции или интерфейса. Один авторский отрицательный текст проверен против трёх PDF, подсветок нет. Три специальные проверки ошибочных границ из предыдущей таблицы не получили нового неверного слова или склейки колонок.

Полностью проинвентаризированы 99 блоков различий токенов: в D06 десять соединений частей русских слов, 16 соединений математических обозначений, 16 разделений и 35 изменений порядка или иной токенизации формул; в D20 двадцать соединений частей слов, в D16 два. Обычные соединения выглядят как исправление разорванных слов, но математические последовательности требуют отдельной проверки исходного расположения.

Независимая проверка выявила два искусственных математических запроса, для которых фильтр пропускает новое дословное свидетельство: **0/12 → 12/12** и **6/13 → 13/13** слов. Изображения страниц 14, 17 и 18 подтвердили ошибки: в первом случае в последовательность вставлен нижний номер страницы перед формулой, во втором переставлены основания переменных и индексы. Сверка с извлечённым текстом гарантирует правильность его смещений, но не порядок чтения исходной двумерной формулы. Эти проверки не являются наблюдаемыми ошибками на настоящем входе D06; они проверяют достоверность нового представления. Одного Unicode-фильтра недостаточно, этот вариант отклонён.

## Ограничение дополнительного представления сохранением порядка

Следующее отдельное изменение требует, чтобы все непробельные символы дополнительной выдержки уже присутствовали в основном тексте в том же порядке. Разрешается только различие пробелов; дефисы, пунктуация, буквы и несимволы не подменяются. Новому совпадению прилагаются смещения поддержки в основном тексте, SHA-256 основного текста, его выдержки и общей упорядоченной последовательности. Исходные совпадения остаются без изменений.

| Проверка на сохранённых данных | До проверки порядка → после | Объём |
| --- | ---: | --- |
| Восстановление D06 | 8/8 → 8/8 слов | Один настоящий фрагмент; основной `plain` даёт 7/8 |
| Ошибка с номером страницы и формулой | 12/12 → 0/12 слов | Один искусственный отрицательный пример; основной `plain` даёт 0 |
| Ошибка с порядком индексов | 13/13 → 6/13 слов | Один искусственный отрицательный пример; сохранены только прежние 6 слов `plain` |
| Прежние буквальные контроли | 9/9 → 9/9 | Сохранение гарантировано включением исходных совпадений |
| Новые неверные слитные слова/колонки D16 | 0/3 → 0/3 | Три специальных отрицательных примера |
| Авторский отрицательный текст | 0/3 → 0/3 подсветок | Один текст против трёх разных PDF |

Повторное независимое чтение артефактов подтвердило правильность всех десяти принятых записей дополнительных совпадений: исходные выдержки, смещения поддержки, порядок символов и хеши совпали. Десять записей не означают десять новых находок: часть совпадений уже покрыта основным представлением. На настоящих входах этих трёх случаев добавлено одно слово D06; D20 и D16 не изменились. Пять авторских тестов фильтра, сохранения исходных совпадений и отказа от перестановок прошли.

Это основание для ограниченного опционального подключения и первой проверки заранее отложенных PDF. Ограничения сохраняются: удаление пробелов само по себе не отличает правильное восстановление слова от ошибочного соединения самостоятельных слов; два парсера могут разделять одну ошибку; найденная первая поддержка в основном тексте не устанавливает геометрическое соответствие страницы. На сохранённых PDFium-представлениях проверенные примеры ошибочных границ новых неверных свидетельств не дали. Интеграция, единый бюджет времени и интерфейс пока не проверены.

Ни один из этих вариантов не включён в рабочую версию. Если продолжать дополнительное извлечение, общее время обоих разборов должно укладываться в один прежний пятисекундный бюджет; сбой дополнительного представления должен сохранять исходный результат. Требуются общий предел объёма и проверка достоверности новой выдержки. Одно восстановленное слово не оправдывает добавление заведомо неверных выдержек.
