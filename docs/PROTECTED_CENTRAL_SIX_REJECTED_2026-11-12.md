# Центральные шесть слов: вариант отклонён

Один вариант был зафиксирован **до оценки**: остальные запросы PARA сокращались до центральных шести слов, без новых позиций, изменения порядка или количества. Первые два слота, реальные слоты B2, цитаты и единственный новый запрос PARA относительно DENSE защищены. Проверка полного плана сохраняла B2 побайтно. Других вариантов после результатов не выбирали.

Четыре искусственных выигрыша не увеличили число случаев с общей цепочкой ≥6 слов. Три выигрыша используют один и тот же фрагмент в разных расположениях; это не четыре независимых источника. В D10 лучшая общая цепочка сократилась с шести до четырёх слов: центр пересёк добавленное в проверяемый текст слово. Потеря воспроизведена отдельной проверкой n-грамм.

У D04 локальная цепочка осталась 6 → 6. Это проверка поисковой фразы: семь слов подсветки сайта здесь заново не измерялись.

Изменены 348/348 длинных искусственных планов, 157/162 коротких и 29/30 планов DEV. Число запросов сохранено: 2088, 766 и 167 соответственно; шесть — потолок, не обязательное число для каждого короткого текста. B2 неизменен во всех 540 строках.
