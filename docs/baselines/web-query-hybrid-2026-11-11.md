# Выбор поисковых фраз на 30 настроечных документах

Порядок стратегий в таблице — uniform-quoted-v1, distinctive-paragraph-v1, hybrid-paragraph-v1. У каждого способа тот же предел в шесть фраз и двенадцать страниц на документ. Характерный поиск ранжирует окна по редкости сочетаний в документе. Гибрид делит запросы между равномерными окнами и характерными фразами. При одном запросе он выбирает характерную фразу. Поисковые фразы строятся только по входному тексту.

Размечено 29 участков в 30 документах, из них 18 допускают дословную подсветку. Документов с разметкой, подтверждённой человеком, 0. Закрытые материалы исключены. Эти числа относятся только к диагностике на данном наборе.

## Условия воспроизведения

Для каждой проверки подаются одни и те же 12 сохранённых страниц. Три публикации, откуда взяты сами входные документы, исключены из общей библиотеки. Для двух независимых рассказов об одном событии одно место из двенадцати отведено второму рассказу. При подсчёте покрытия проверяются позиции соответствующих слов и в проверяемом документе, и в нужной редакции источника. Время отдельного прогона зависит от нагрузки компьютера.
