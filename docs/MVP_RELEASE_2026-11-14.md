# Бесплатный MVP Истока — 14 ноября 2026

**Рабочий сайт: https://istoktext.online/**, также www. Он работает без ноутбука. Бесплатный MVP готов для первых пользователей в описанных ниже пределах; соответствие всей платной версии text.ru и её точности не установлено.

Подтверждённое улучшение: отдельный диагностический повтор ранее пропущенной 20-словной вставки нашёл источник и все 20 слов вместо 0. Оставшееся ограничение: поиск коротких вставок всё ещё неполон; первоначальный новый набор сохранён с 40/70 слов, без замены неудач повторами.
