## Квота и сохранение

Владелец разрешил превысить прежний ночной предел 24 при наличии бесплатной квоты. Перед запуском API Tavily показывал Researcher, 26 использованных из 1000 кредитов, нулевой платный перерасход. Локальный месячный журнал содержал 37 попыток, после проверки — 38. Для нового запуска отдельно проверен запас бесплатных кредитов и заранее ограничен план одной фразой. Всего в ночных экспериментах выполнено 25 поисковых попыток.

После проверки API снова показал 26 из 1000 и нулевой платный перерасход. Начисление этого конкретного запроса в счётчике API пока не отразилось. Кабинет оплаты не удалось повторно открыть из-за сохранённой настройки доступа браузера. Прогон выполнен в подтверждённом запасе бесплатной квоты. Платные планы и автопополнение не подключались, вызовов GPU не было.

Приватные файлы `data/private/web-evaluation/d04-fresh/` содержат запрос, снимки квоты до и после, полный отчёт и проверку выдержки. Код поиска в этом этапе не менялся, повторный запуск существующего идентификатора не создаёт новую проверку.
