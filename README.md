# Исток

Бесплатная бета проверки заимствований по интернету. Исток составляет поисковые фразы, находит страницы через Tavily, загружает доступный текст и показывает совпавшие фрагменты со ссылками. Интернет-режим работает без Qwen и GPU. В MVP есть также проверка по своей библиотеке. Экспериментальная смысловая сверка Qwen/BGE-M3 не включена в публичный бесплатный релиз.

**[Онлайн-бета Истока](https://istoktext.online/)** работает на CPU в Modal независимо от ноутбука. Гостевые отчёты сохраняются на сервере и разделены по браузерам; регистрация и оплата отложены. [Условия бесплатной беты и проверка публикации](docs/ONLINE_BETA.md). Локальная копия с прежними личными данными и ночными отчётами остаётся на Mac. Документы TXT/MD/DOCX/ODT/RTF/HTML/DOC и текстовые PDF, личная панель данных, словарный корректор и API владельца описаны в условиях беты. Дополнительный корректор Qwen включается отдельно и использует ограниченные бесплатные кредиты Modal; [границы и проверка](docs/QWEN_CORRECTOR_2026-11-14.md).

Поиск дополнительно дочитывает до двух равноценных ссылок с уже прочитанных страниц, сохраняя прежние результаты и общий лимит чтения. На сохранённом искусственном пропуске это вернуло40/40слов без новых поисковых запросов. [Результат обновления, ограничения и рабочие отчёты](docs/SEARCH_UPDATE_2026-11-12.md).

Дополнительный поиск распределяет фразы по разным абзацам и использует неподтверждённый участок, когда второй запрос уже покрыт найденным текстом. В искусственном примере про метрологию исправлен пропуск10/10слов; служебные кнопки редактирования MediaWiki исключаются из извлечённого текста. [Результаты и границы проверки](docs/SHORT_INSERT_FIX_2026-11-12.md). Прежние исправления [17слов про фотографию](docs/USER_PHOTO_FIX_2026-11-12.md) и [18слов про Деймос](docs/DEIMOS_SEARCH_FIX_2026-11-12.md) сохранены.

**[Итог проверенного релиза 13 ноября](docs/MVP_RELEASE_2026-11-13.md)**: 948 серверных тестов (1 пропущен), 67 интерфейсных, DOCX/PDF, история, проверенное восстановление; код 8b062d6.

Инструкции текущего релиза: [эксплуатация, ошибки квоты, резервная копия и откат](docs/RELEASE_OPERATIONS_2026-11-13.md). Бесплатный MVP поддерживает TXT/MD, DOCX и текстовый PDF (до1МиБ, PDFдо40страниц, безOCR) и доступные источники; качество text.ru не установлено.

[Матрица требований по платным возможностям text.ru](docs/PAID_FEATURE_REQUIREMENTS_2026-11-13.md): функциональный ориентир без покупки проверок и без вывода о платной точности по бесплатной версии.

## Запуск

Нужен Python 3.11 или новее. Лексическая часть и интернет-поиск используют стандартную библиотеку Python. Ограниченный разбор текстовых PDF дополнительно требует закреплённого `pypdf` из `requirements-pdf.txt`. Node.js нужен для проверок разработки. В текущей бете настроен Tavily, локальные и облачные модели отключены. [Инструкция запуска, проверки готовности и восстановления](docs/LOCAL_BETA_LAUNCH_2026-11-12.md).

PDF-зависимость устанавливается в выбранном виртуальном окружении с проверкой хеша

```sh
python -m pip install --require-hashes --only-binary=:all: -r requirements-pdf.txt
```

Откройте `Запустить Исток.command` или выполните в папке проекта

```sh
python3 scripts/start.py --web-only
```

Приложение доступно на <http://127.0.0.1:8766>. На главной есть отдельное поле интернет-проверки, сохраняющее рабочий черновик редактора. Редактор с вкладками «Интернет» и «Библиотека» — <http://127.0.0.1:8766/#check>. Процесс работает до закрытия терминала или Ctrl+C.

Режим `--web-only`, используемый кнопкой запуска, отключает Ollama и Modal. Прежний режим без этого флага при наличии `.runtime/cloud-models.json` выбирает `ISTOK_MODEL_PROVIDER=modal` и Python из `.runtime/modal-venv`; он оставлен для отдельно разрешённой работы с моделями.

Локальная база — `data/istok.sqlite3`. Черновики главной и редактора, выбранная модель, несохранённые комментарии и запросы активных заданий сохраняются в браузере. Для восстановления используйте тот же браузер и адрес с портом 8766. В SaaS-режиме хранилища и браузерные ключи разделены по аккаунтам; этот режим пока не опубликован.

## Первая проверка

1. Вставьте открытый или авторский текст в поле на главной либо выберите вкладку «Интернет» в редакторе.
2. Подтвердите отправку поисковых фрагментов внешнему поисковому сервису и нажмите «Проверить уникальность». При отсутствии ключа кнопка недоступна и объясняет причину.
3. Откройте найденные ссылки, сравните выдержки и прочитайте сведения об охвате. Отчёт сохраняется в истории и скачивается как автономный HTML или JSON.
4. Для собственных материалов выберите «Библиотека». Подборки по экономике и биологии устанавливаются на экране источников; свои тексты можно вставлять или загружать из TXT/MD.
5. Смысловая сверка и предложения правок доступны отдельно. Сначала просмотрите доказательные фрагменты и предпросмотр правки. Оформленная цитата продолжает совпадать с источником.

Tavily подключён в текущем рабочем экземпляре. В новой копии проекта ключ задаётся через локальную операторскую страницу `/setup-search.html`. Она недоступна в публичном SaaS-режиме. Ключ хранится в исключённом из Git `.runtime/search-api.json` с правами `0600`, не возвращается в статусе и не печатается в отчёте. Статус конфигурации читается без поискового запроса.

Облачная интеграция работает в тестовом режиме `synthetic_only=true`. В проверках использовались авторские примеры и открытые фрагменты; личный черновик в облако не отправляли. При явном запуске модельной операции выбранный текст и фрагменты источников передаются Modal. Тестовый флаг обозначает этап проверки продукта и не распознаёт автоматически личные данные. Для текущих проб используйте учебный пример или открытый текст.

Личный экономический черновик на 4370 символов не отправлялся ни в Modal, ни в поисковый сервис. Он остаётся отдельным черновиком редактора.

Интернет-проверка выполняет до шести поисковых запросов. Сначала она пытается прочитать до двенадцати страниц. Если доказанных дословных совпадений нет, проверка продолжает уже найденную очередь: ещё до двенадцати страниц, максимум 24 попытки, с ограничением оставшегося времени. Новых поисковых запросов это продолжение не добавляет. Явно названная в документе статья русской Википедии также проверяется по её странице; само указание источника доказательством не считается. [Проверка продолжения очереди и ограничения](docs/ZERO_FALLBACK_2026-11-12.md).

Поисковый сниппет не является доказательством совпадения. Совпадения вычисляются по загруженному тексту, а уникальность — по доле слов без найденного дословного совпадения. При неполном поиске окончательный процент не устанавливается. Если совпадения уже дают верхнюю границу, интерфейс показывает «Не выше …%», включая значимый ноль. Повторы сохранённых данных помечены в интерфейсе отдельно от свежего поиска.

Ноль прочитанных источников не даёт 100% уникальности. При расчёте по словам похожее совпадение не скрывает дословное; верхняя граница округляется вверх до 0,1 процентного пункта. Версии запроса и matcher, найденные/проверенные/пропущенные URL сохраняются для диагностики.

В режиме библиотеки доля совпадений рассчитывается по объединению найденных символьных интервалов относительно всей длины текста. Пробелы внутри интервалов учитываются, пересечения считаются один раз. Это отдельный показатель, а не уникальность по интернету. Решения редактора и кандидаты поиска по смыслу сохраняются отдельно от процентов.

## Что показали живые интернет-проверки

Проведены два smoke-прогона копий фрагментов одной публичной статьи Википедии «Экономика». Backend получил только `request_id`, `text` и `internet_consent`; ожидаемый URL ему не передавался. В обоих случаях исходная страница найдена, все слова копии получили дословные совпадения.

| Вход | Время | Поисковые запросы | Загружено страниц | Совпавшие слова |
| --- | ---: | ---: | ---: | ---: |
| 756 символов, 90 слов | 14,647 с | 2 | 4 | 90/90 |
| 6 000 символов, 710 слов | 31,335 с | 6 | 5 | 710/710 |

Оба отчёта имеют `web.status=partial`, `uniqueness_percent=null` и верхнюю границу уникальности 0%. Были недоступные или запрещённые страницы, PDF и, в длинном прогоне, ссылки за лимитом загрузки. Это подтверждение работающего поиска скрытого источника и проверка времени на двух длинах одной статьи. Точность на разных статьях, пересказах и независимых текстах ещё не доказана. Повторная отправка сохранённого задания не добавила новых поисковых запросов.

Артефакты — `data/runs/live-web-hidden-source-smoke.json`, `live-web-6000-smoke.json` и `site-web-idempotence-check.json`. Они исключены из Git. Интернет-режим не вызывает модель и не использует GPU.

## PDF и охват

Для страниц-источников добавлен ограниченный разбор текстовых PDF в отдельном процессе — до 1 MiB, 40 страниц и 200 000 извлечённых символов. OCR не выполняется; зашифрованные, слишком большие и неподдерживаемые документы дают явную ошибку охвата. Загрузка PDF пользователем в редактор пока не поддерживается.

Два первоначальных публичных PDF-smoke завершились ограничениями размера и числа страниц (`data/runs/pdf-source-smoke.json`). В ночном повторе 12 ноября дополнительный текст PDFium восстановил последнее слово D06: 7 → 8/8 слов на тех же сохранённых байтах. Девять буквальных контролей трёх PDF сохранены; первая проверка одного нового PDF сохранила 210/210 слов девяти зависимых цитат, два независимых контроля не подсвечены. Это ограниченная проверка, не оценка точности на любых PDF. [Политика и доказательства](docs/PDF_ALTERNATIVE_VIEW_DESIGN_2026-11-12.md).

Основной парсер остаётся `pypdf 7.0.1`. Дополнительный `pypdfium2 5.14.0` используется только если уже доступен и явно включён: `ISTOK_PDF_ALTERNATIVE_ENGINE=pdfium`, `ISTOK_PDFIUM_PYTHON=/абсолютный/путь/к/python`. Для постоянного локального запуска `scripts/start.py` читает `.runtime/pdf-extraction.json` с полями `engine: "pdfium"` и `python`; настройки окружения имеют приоритет. Автоматической установки нет. Два снимка ограничены общими пятью секундами и 200 000 знаками; дополнительный отказ сохраняет основной результат. Новая exact-выдержка принимается лишь при подтверждении теми же непробельными знаками в том же порядке в основном снимке. Недоступные PDF, robots-ограничения, закрытые сайты и предел числа загрузок остаются причинами неполного отчёта.

## Код SaaS и состояние подключения

Реализованы вход с подтверждением почты через OTP, Turnstile, CSRF, разделение данных аккаунтов и серверный учёт квот. В бесплатной конфигурации предусмотрены 6 000 знаков, до трёх проверок, 60 модельных операций и трёх правок в сутки, один поиск кандидатов на отчёт. Повтор использует тот же идентификатор и сохранённое тело. Гостевой черновик не прикрепляется к новому аккаунту автоматически; выход и смена аккаунта выполняют полную перезагрузку.

Supabase, Turnstile и доставка писем ещё не подключены и не проверены на реальных регистрациях. Общий сайт не размещён, платежи пользователей не принимаются. Обходы учёта квоты устройства исправлены и проверены HTTP-регрессиями, стоимость пакетов embedding резервируется до вычислений. До публикации нужен живой SaaS-прогон на размещённом сайте. IP сам по себе не доказывает мультиаккаунт.

Код обратной связи для будущего обучения использует отдельное явное согласие, ограниченную пару фрагментов, отзыв согласия и ручное решение о правах/разметке перед экспортом. Обычное решение редактора по находке не означает согласия на обучение. Автоматического дообучения нет.

## Библиотека и открытые подборки

В текущей рабочей базе находятся 32 источника — 30 реальных русскоязычных статей из Википедии и два учебных материала. Экономический набор содержит 14 статей и 171 685 символов, биологический — 16 статей и 349 383 символа. Наборы хранятся в `data/source-packs/economics-ru-v1.json` и `data/source-packs/biology-ru-v1.json`, устанавливаются через экран библиотеки. Повторная установка сохраняет уже добавленные материалы. Пользовательские источники остаются в библиотеке.

У публикаций сохранены авторская атрибуция, лицензия CC BY-SA 4.0, ссылка на историю авторства, сообщённая API редакция, время получения и SHA256 извлечённого текста. В интерфейсе доступны сведения об авторстве и лицензии. Полный полученный обычный текст сохранён без обрезания. MediaWiki одновременно сообщает последнюю редакцию, тождество извлечения именно этой редакции отдельно не подтверждалось. Эта граница отражена в `provenance.revision_binding`.

Подборки служат начальной библиотекой для редакторских проб. Независимая разметка реальных заимствований по этим статьям ещё предстоит. Числа диагностических прогонов ниже получены на специально написанных синтетических примерах.

Отчёты сохраняют снимки источников и остаются читаемыми после удаления материала из библиотеки. Одинаковые снимки дедуплицируются по SHA256. Поддерживается чтение старых отчётов с вложенными текстами.

## Импорт и черновики

Текст статьи и отдельный источник могут содержать до 200 000 Unicode-символов. Ограничение проверяется явно при вводе, импорте и на сервере. Длинный вставленный текст сохраняется с видимым сообщением об ограничении.

Поддерживаются UTF-8 и UTF-16LE/BE с BOM. При некорректном UTF-8 без BOM пробуется Windows-1251, предположительная кодировка отмечается в интерфейсе. Двоичные данные, NUL и неподдерживаемые кодировки отклоняются до замены текста. Отложенное чтение файла сохраняет более новую правку пользователя.

Изменение текста помечает предыдущий отчёт устаревшим. История предлагает явное восстановление текста отчёта, сохраняя текущий черновик при открытии. Комментарии к находкам и учебным парам сохраняют новые изменения, сделанные во время ожидания ответа сервера.

## Модели и границы доказательств

По прямому указанию пользователя локальные вычисления остановлены из-за нагрева Mac. Модели `qwen3:4b` и `qwen3.5:9b` удалены. Процессов Ollama после остановки не обнаружено.

В `.runtime/models` остаются файлы BGE-M3 размером около 1,1 ГБ. Локальная BGE также остановлена; рабочий поиск по смыслу обращается к серверной BGE. Маркер `.runtime/local-inference-disabled` сохраняет запрет автозапуска, а `scripts/start.py` запускает сайт с облачным транспортом.

Возобновлять локальные модели, скачивать их заново или снимать маркер разрешается только после нового явного согласия пользователя. Это ограничение относится и к локальным диагностическим прогонам, и к поиску по смыслу.

Облачный режим задаётся `ISTOK_MODEL_PROVIDER=modal`, проверенные имена и digest моделей находятся в `.runtime/cloud-models.json`. Изменение имени в интерфейсе не позволяет запустить произвольную модель. При недоступности сервиса или несовпадении контрольных сумм проверка прекращается. Исторические локальные измерения выполнялись через loopback Ollama с `think=false`, контекстом 8192, Flash Attention и KV-кешем `q8_0`.

Qwen выбирает предложения по идентификаторам. Программа извлекает точные исходные выдержки и их границы. Адаптер `sentence-selection-v5-literal-availability` исключает `exact` из схемы ответа, когда среди предложенных пар нет буквального совпадения по действующим порогам. Инструкция и пороги сохранены; программа не подменяет ответ модели меткой `paraphrase`. Выбранная дословная выдержка проходит дополнительную проверку. После повторно неподтверждённой метки пара получает состояние «Нужна проверка редактора», без подготовки правки.

Для правки кандидата сервер требует актуальную сохранённую положительную оценку. Предпросмотр показывает исходную выдержку, применение проверяет неизменность текста, идентификатор оценки и границы замены. Соседние авторские предложения сохраняются. Оформление цитаты для лексического совпадения доступно без модели.

## Поиск и фоновые задания

Поиск по словам использует BM25, поиск по смыслу — BGE-M3. На каждый фрагмент статьи выводится до пяти кандидатов. Сильнейший смысловой кандидат сохраняется в пятёрке при отсутствии общих слов. Это поведение проверялось на синтетических переводных примерах.

Представления источников кешируются локально по содержимому и контрольной сумме модели. Первая обработка библиотеки занимает больше времени, чем повторная.

Массовая проверка кандидатов показывает прогресс, четыре метки модели, случаи для ручной проверки и ошибки. Остановка дожидается текущего ответа модели, уже завершённые сравнения сохраняются по одному. После перезагрузки страницы возобновляется наблюдение за активными заданиями. При временной потере связи используются повторные подключения с задержками до 15 секунд. Частичные ответы массовой проверки остаются в базе после перезапуска сервера.

Одиночные сравнения, правки и учебная оценка используют `/api/model-jobs`: один worker, до трёх активных заданий, постоянный идентификатор запроса. Повторная отправка того же запроса возвращает прежнее задание. Завершённый результат или ошибка читается с диска после перезапуска. Незавершённое задание помечается прерванным без автоматического повторного обращения к модели. Неудачная повторная проверка кандидата сохраняется отдельно и не восстанавливает прежний положительный вердикт. Учебная оценка показывает число сравнённых пар.

## Диагностика качества и скорости

`data/examples.json` содержит 12 авторских синтетических пар. Четыре относятся к обучающей части, восемь — к диагностической. Исходные тексты этих частей разделены, однако диагностические пары уже использовались при настройке инструкций. Экспорт для обучения включает только вручную просмотренные примеры обучающей части. Дообучение модели ещё не проводилось.

`data/retrieval_examples.json` содержит 24 синтетических случая и 16 документов-источников. В тестовой части 16 случаев, включая 12 положительных и четыре независимых текста. Оцениваются попадание нужного источника и фрагмента в первые результаты, затем решение Qwen на найденной паре. Эти данные также использовались для отладки.

`scripts/evaluate.py` оценивает размеченные пары, `scripts/evaluate_retrieval.py` — поиск источников, `scripts/evaluate_pipeline.py` — всю цепочку. `scripts/benchmark_model.py` сохраняет время запросов, токены, наличие thinking, контекст и показатели резервирования памяти Ollama. Запуски с локальными моделями сейчас требуют нового явного разрешения пользователя.

Показатель Ollama `size_vram` на Mac с общей памятью не равен полному потреблению физической RAM компьютера. На Linux отдельно сохраняются системная память из `/proc/meminfo` и память GPU из `nvidia-smi`, если он доступен. Лимит памяти контейнера из этих показателей не выводится.

Для сопоставления прогонов сохраняются digest модели, SHA256 кода, отпечаток данных, порядок и точные тексты кандидатов. Читать и проверять уже сохранённые результаты можно без запуска моделей

```sh
python3 scripts/evaluate_pipeline.py --audit-existing data/runs/qwen4b-current.json --output data/runs/qwen4b-current-audited.json
```

`scripts/compare_pipeline_runs.py` сравнивает два готовых полных JSON и отклоняет несопоставимые данные, код или кандидатов. Он выводит полноту по размеченным случаям, ложные положительные находки, неопределённые ответы, ошибки, число запросов и медиану/p95 времени без кешированных ответов. Прерванный прогон 9B требует отдельного рассмотрения частичных данных.

## Сохранённые диагностические результаты

Для прототипа выбрана Qwen3.5 9B с адаптером v5. Полный серверный прогон на 16 синтетических статьях и 80 найденных парах завершён за 176,600 секунды, 80 запросов. Найдены 12/12 ожидаемых источников и участков, дополнительных положительных выдержек вне ожидаемого участка, неопределённых пар и ошибок нет. На четырёх специально написанных независимых статьях положительных находок нет.

Эти примеры использовались при разработке. Результат не является независимой оценкой точности на реальных статьях и не означает определение любого плагиата. Полное сравнение серверных 4B, 9B и 32B, границы метрик и изменение v5 описаны в [результатах испытаний](docs/MODEL_RESULTS.md).

Артефакты находятся в исключённом из Git `data/runs/`:

- `modal-qwen9b-v5-cloud-20261111.json` — выбранная версия 9B/v5; отдельный `-resources.json` содержит время подготовки, digest и параметры среды.
- `modal-qwen4b-cloud-20261111.json`, `modal-qwen9b-cloud-20261111.json`, `modal-qwen32b-20261111.json` — исходные сопоставимые серверные испытания адаптера v4.
- `qwen4b-current.json` — исторический полный локальный 4B: 804,627 с, 84 запроса, 12/12 ожидаемых источников и участков, одна неопределённая пара. Результат относится к прежнему локальному окружению.
- `qwen9b-interrupted.json` — прерванный локальный 9B: 69 сохранённых успешных пар, 11 отсутствующих, `status=interrupted`, `metrics=null`. Полные метрики этого запуска не вычислялись.
- Старые `baseline.json`, `grounding-v2.json`, `grounding-v3.json`, `retrieval-baseline.json`, `retrieval-v2.json`, `pipeline-v1.json`, `pipeline-v1-audited.json`, `pipeline-v2.json` и `qwen35-9b-smoke.json` сохранены для истории разработки.

Снимок v5 до подключения транспорта сохранён локальным коммитом `62697b3`. Для сравнения версий с различающимися адаптерами нужны явные оговорки о коде и точных входных парах; [протокол оценки](docs/EVALUATION_PROTOCOL.md) описывает следующий независимый этап.

## Подключённый облачный сервис

Приватный [Modal App `istok-inference`](https://modal.com/apps/zhanlaiman/main/deployed/istok-inference) обслуживает реальные запросы сайта через аутентифицированный SDK. Выбранные модели — `qwen3.5:9b` и BGE-M3 на одной L40S. Максимум один контейнер, минимум ноль, окно простоя 60 секунд, подготовка ограничена 600 секундами, одна модельная операция — 180 секундами. Веса находятся на временном диске контейнера; постоянных Volumes и публичного модельного endpoint нет. Холодный запуск включает получение весов и занимает дополнительное время.

Статус сайта каждые 15 секунд читает только локальный manifest и сохранённые сведения о последнем запросе. Он показывает готовность конфигурации, не проверяет прогретость GPU и не подтверждает текущую авторизацию. Реальная HTTP-проверка 100 опросов статуса не добавила ни одного облачного вызова: до и после оставалось два. Артефакт — `data/runs/site-cloud-status-check.json`.

Прямые приватные проверки embedding и переводной пары прошли, границы выдержек сохранились. Учебная оценка из восьми пар прошла через интерфейс и `/api/model-jobs`; обновление страницы восстановило наблюдение, результат сохранён. Живая HTTP-проверка правки авторского демо подтвердила цитирование и сохранность исходного отчёта. Повторная отправка того же задания не создала новый облачный вызов. Артефакт — `data/runs/site-cloud-rewrite-check.json`.

Поиск по 30 публичным статьям (521 068 символов, 755 фрагментов) нашёл ожидаемую статью «Фотосинтез» первой. Начальный прогон с 759 новыми представлениями занял 233,291 секунды; кеш сохранён для повторного использования. Это синтетический поисковый запрос на реальном корпусе, не независимая оценка точности. Артефакт — `data/runs/public-corpus-retrieval-check.json`.

Пользователь предоставил доступ SDK на 12 часов. Конфигурация `.runtime/modal-config.toml` имеет права `0600` и исключена из Git; её содержимое не публикуется. В аккаунте проверены Starter с кредитом $30, Usage limit $30 и custom Spend limit $0. При последней ручной сверке 11 ноября интерфейс показывал $1,77 использованных кредитов, $0 расходов с карты и $28,23 остатка. Это датированный снимок, а не текущий баланс или стоимость одной статьи. Детали сервиса и диагностических запусков находятся в [облачной инструкции](cloud/README.md).

## Отчёт для чтения

В сохранённом отчёте кнопка «Отчёт для чтения» скачивает автономный HTML. Он содержит пары выдержек, решения и комментарии редактора, последние сохранённые оценки или ошибки Qwen, проверенную версию текста и список источников с атрибуцией. Его можно открыть без сайта и распечатать средствами браузера. Данные JSON доступны отдельной кнопкой.

Экспорт использует снимки источников именно этого отчёта. Последняя неудачная перепроверка не заменяется прежним положительным ответом. Генерация файла не вызывает модель и не загружает внешние ресурсы. Указывается область проверки — интернет или библиотека, а для веб-отчёта сохраняются частичный статус, ошибки и границы процента. Просмотр — `/reports/{id}.html`, данные для скачивания — `/api/report-exports/{id}`; в SaaS действует проверка принадлежности отчёта аккаунту.

Node-набор проверяет черновики, границы правок, восстановление заданий, SaaS-сессии, интернет-согласие, частичные результаты и скачивание исходного отчёта после переключения. Визуальную проверку выполняют отдельно.

Новая светлая главная проверена в разрешённом браузере настоящей отправкой открытого фрагмента. Найден источник, показаны результат и ссылки; личный черновик редактора остался отдельным.
